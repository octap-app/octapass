All Octa Pass code (the core, server, apps, extensions, CLI and website) is licensed under the **MIT License** (`MIT`). The full text is in [`LICENSE`](https://github.com/octap-app/octapass/blob/main/LICENSE).

## What that means

| You can | Conditions |
|---|---|
| Use Octa Pass for any purpose, personal or commercial | None |
| Study and modify the code | None |
| Share copies or modified versions | Keep the copyright and licence notice |
| Run a modified version as a service for others | None |

MIT is a permissive licence: there's no requirement to publish changes. The hosted service at `vault.octap.app` still runs exactly the code in this repository, by choice, and every release is built from a public commit.

## One codebase, no open core

There's no proprietary edition. The free hosted service runs exactly the published code, and self-hosters get every feature.

## Contributions

Contributors sign off commits under the Developer Certificate of Origin (`git commit -s`). There's no Contributor Licence Agreement: you keep the copyright to your contribution and license it under MIT. Source files carry an SPDX header:

```text
SPDX-License-Identifier: MIT
```

## Name and logo

The licence covers the code, not the name. A trademark policy will allow forks while preventing confusing use of the "Octa Pass" name. See the [FAQ](/docs/reference/faq/#is-octa-pass-the-final-name) for the name's history.
