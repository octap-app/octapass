:::note[قيد التطوير]
تطبيقات سطح المكتب مبنية لأنظمة macOS وWindows وLinux، لكنها غير مُصدَرة: لا توجد تنزيلات عامة موقّعة بعد. يمكنك [بناؤها من المصدر](/ar/docs/contributing/development-setup/#بناء-التطبيقات). ليس في تطبيق Mac الأصلي بعدُ الكتابة التلقائية ولا Wi-Fi ولا الدخول الموحّد، وسينتقل Windows وLinux إلى تطبيقات أصلية أيضًا.
:::

هناك تطبيقان لسطح المكتب على نواة Rust نفسها:

- **على Mac** يكون Octa Pass تطبيق SwiftUI أصليًا، مبنيًا من شاشات تطبيق iPhone وiPad نفسها. انظر [تطبيق Mac](#تطبيق-mac).
- **على Windows وLinux** هو تطبيق Tauri 2 يعرض شاشات خزنة الويب. ويرتبط جانب Rust فيه بنواة Octa Pass مباشرة، ولا تحتفظ الواجهة بمفاتيح التشفير أبدًا؛ فهي تتلقى فقط الحقول المفكوكة التي تطلبها. وستحلّ تطبيقات أصلية محلّه هناك أيضًا ([الخطة 19](https://github.com/octapass/octapass/blob/main/plans/19-native-desktop-apps.md)).

بقية هذه الصفحة، من [الميزات](#الميزات)، عن تطبيق Windows وLinux ما لم تذكر غير ذلك.

## المنصات والحزم

| نظام التشغيل | الحزمة | الفتح |
|---|---|---|
| macOS 14+ | تطبيق أصلي وصورة قرص، موقَّعان للتطوير. لم يُعَدّ بعدُ التوقيع بـ Developer ID والتوثيق (notarisation) للتنزيلات العامة. | Touch ID أو كلمة مرور جهاز Mac |
| Windows 10/11 | مثبّت NSIS. توقيع الشيفرة مخطط له. | Windows Hello |
| Linux | AppImage و.deb و.rpm. حزم Flatpak وAUR مخطط لها. | polkit (كلمة مرور النظام أو بصمة الإصبع)، وإلا كلمة المرور الرئيسية |

## تطبيق Mac

في تطبيق Mac شاشات تطبيق iPhone وiPad داخل نافذة Mac: شريط جانبي، وقائمة العناصر، والعنصر، ويُفتح المحرر داخل النافذة لا في ورقة منفصلة. والإعدادات نافذة مستقلة (**Cmd+,**)، وفي القوائم بيانات دخول جديدة (**Cmd+N**) والبحث (**Cmd+F**) ونسخ اسم المستخدم أو كلمة المرور أو الرمز لبيانات الدخول المفتوحة، والقفل (**Ctrl+Cmd+L**).

- **الفتح** بـ Touch ID أو كلمة مرور جهاز Mac، أو بكلمة المرور الرئيسية. ويعمل **البقاء مفتوحًا ما دمت مسجّل الدخول** كما على iPhone.
- **[الملء التلقائي](#الملء-التلقائي-في-macos)** لكلمات المرور ومفاتيح المرور والرموز لمرة واحدة في Safari والتطبيقات الأخرى، حتى والتطبيق مغلق.
- **[الخزائن](/ar/docs/features/octa-pass-safe/) في Finder**، تحت «المواقع»، ما دامت الخزنة مفتوحة.
- **[روابط الرموز لمرة واحدة](#إعداد-الرموز-لمرة-واحدة-على-mac)** و**[تبادل بيانات الاعتماد](#الانتقال-من-مدير-كلمات-مرور-آخر-على-mac)** مع مديرات كلمات المرور الأخرى.
- **[الوصول السريع](#الوصول-السريع-على-mac)** إلى كل العناصر من أي مكان (**Cmd+Shift+Space** أو شريط القائمة)، و**الفتح عند تسجيل الدخول** (الإعدادات ← التشغيل في الخلفية).

- **تُفتح إضافة المتصفح وواجهة سطر الأوامر عبر التطبيق**، بـ Touch ID أو كلمة مرور Mac: **الإعدادات ← إضافة المتصفح ← ربط إضافة المتصفح** مرة واحدة (انظر [المتصفحات المدعومة](#المتصفحات-المدعومة))، ويستخدم [`octapass`](/ar/docs/platforms/cli/#استخدام-حساب-تطبيق-سطح-المكتب) حساب التطبيق، مفتوح القفل كلما كان التطبيق مفتوحًا.
- **[وكيل SSH](/ar/docs/features/ssh-keys/#وكيل-ssh)**، ويُشغَّل من **الإعدادات ← وكيل SSH**. يعمل التطبيق في عزلة (sandbox)، فتوجّه SSH إليه بنفسك: تعرض الإعدادات الأسطر التي تضيفها إلى `~/.ssh/config`.

هذه الثلاثة جديدة في تطبيق Mac ولم تُجرَّب بعدُ مع متصفح وطرفية وخادم SSH حقيقية.

ليس في تطبيق Mac بعدُ: الكتابة التلقائية، وWi-Fi، والدخول الموحّد (SSO). وهي قيد الإضافة ([الخطة 19](https://github.com/octapass/octapass/blob/main/plans/19-native-desktop-apps.md)).

يحتفظ تطبيق Mac بمخزن خزنة خاص به. إن كنت تستخدم تطبيق Tauri السابق على Mac، فسجّل الدخول من جديد في التطبيق الجديد، وستُزامَن عناصر حسابك إليه. أما [الخزنة دون حساب](/ar/docs/features/local-vault/) فلا تُنقل: صدّرها من التطبيق القديم أولًا، ثم استوردها في التطبيق الجديد.

### الوصول السريع على Mac

اضغط **Cmd+Shift+Space** في أي تطبيق، أو اختر **الوصول السريع** من أيقونة شريط القائمة، فتظهر لوحة بحث فوق التطبيق الذي تعمل فيه. تعرض اللوحة كل عناصر خزنتك مجمّعةً حسب النوع كما في نافذة الخزنة: بيانات الدخول، وكلمات المرور، والبطاقات، والهويات، والملاحظات الآمنة، وشبكات Wi-Fi، ومفاتيح SSH، والمستندات، والبيئات، والحسابات المصرفية، ووثائق الهوية، ومحافظ العملات المشفّرة، وبيانات اعتماد API، وقواعد البيانات، وتراخيص البرامج، والعناصر المخصّصة. وما تكتبه يُبحث عنه فيها كلها: في العنوان واسم المستخدم والموقع والوسوم.

| المفتاح | ما يفعله |
|---|---|
| السهم لأعلى ولأسفل | التنقّل بين النتائج |
| Return | الإجراء الأول للعنصر المحدّد (انظر أدناه) |
| من Cmd+1 إلى Cmd+9 | إجراءاته الأخرى، بالترتيب الذي تعرضه **الإجراءات** |
| Cmd+K | **الإجراءات**: كل ما يمكنك فعله بالعنصر، مع اختصاراته |
| Cmd+O | فتح العنصر في نافذة الخزنة |
| Ctrl+Cmd+C وShift+Cmd+C وOption+Cmd+C | اسم المستخدم أو كلمة المرور أو الرمز لمرة واحدة لبيانات الدخول، كما في نافذة الخزنة |
| Esc | إغلاق قائمة الإجراءات، ثم اللوحة |

ينسخ Return ما تحتاجه عادةً من كل نوع:

| النوع | ينسخ Return | وفي الإجراءات أيضًا |
|---|---|---|
| بيانات الدخول، كلمة المرور | كلمة المرور (أو اسم المستخدم إن لم تكن هناك كلمة مرور) | اسم المستخدم، والرمز لمرة واحدة، والموقع، والحقول المخصّصة، والملاحظات |
| البطاقة | رقم البطاقة | تاريخ الانتهاء، ورمز الأمان، والاسم على البطاقة، ورمز PIN، والملاحظات |
| الهوية | الاسم | البريد الإلكتروني، والهاتف، والعنوان، وتاريخ الميلاد، والملاحظات |
| الملاحظة الآمنة | الملاحظة | |
| شبكة Wi-Fi | كلمة المرور | اسم الشبكة، واسم المستخدم |
| مفتاح SSH | المفتاح العام | البصمة، والمفتاح الخاص، وعبارة المرور، والملاحظات |
| البيئة | المتغيّرات بصيغة `.env` | قيمة كل متغيّر، والملاحظات |
| الحساب المصرفي | رقم IBAN، أو رقم الحساب | حقول الحساب الأخرى |
| بيانات اعتماد API | المفتاح، أو السرّ | اسم المستخدم، والمضيف، وتاريخ الانتهاء |
| ترخيص البرنامج | مفتاح الترخيص | المنتج، والبريد الإلكتروني، ورقم الطلب وبقية الحقول |
| وثيقة الهوية | رقم الوثيقة | الاسم، والتواريخ، وجهة الإصدار، والبلد |
| محفظة العملات المشفّرة | عنوانها الأول | العناوين الأخرى، واسم المحفظة، وعبارة الاسترداد، وعبارة المرور |
| قاعدة البيانات أو الخادم | كلمة المرور، أو سلسلة الاتصال | المضيف، والمنفذ، وقاعدة البيانات، واسم المستخدم |
| العنصر المخصّص | حقله الأول | حقوله الأخرى |
| المستند | ملاحظاته، أو يفتحه | |

تُمسح الأسرار (كلمات المرور، وأرقام البطاقات ورموزها، والمفاتيح، والحقول المخفية، والملاحظات) من الحافظة بعد 30 ثانية كما في نافذة الخزنة، وتُعلَّم كي تتجاهلها برامج إدارة الحافظة والحافظة العامة (Universal Clipboard). وما دامت الخزنة مفتوحة فلا يُطلب منك التأكيد عند النسخ. وإن كانت مقفلة، تعرض اللوحة الفتح بـ Touch ID أو بكلمة مرور Mac، أو تفتح نافذة الخزنة لكلمة المرور الرئيسية.

## الميزات

- **الوصول السريع:** اختصار عام يفتح مربع بحث للنسخ أو الملء أو الكتابة التلقائية.
- **يعمل في الخلفية:** إغلاق النافذة لا يُنهي Octa Pass. تفتحه أيقونة في شريط القائمة أو علبة النظام، ويُفتح عند تسجيل دخولك إلى الحاسوب. انظر [التشغيل في الخلفية](#التشغيل-في-الخلفية).
- **الكتابة التلقائية:** تكتب اسم المستخدم وكلمة المرور في التطبيق المُركَّز عليه بعد التحقق من أن النافذة تطابق العنصر. انظر [الكتابة التلقائية](#الكتابة-التلقائية).
- **الرموز لمرة واحدة من رموز QR:** في بيانات الدخول، يقرأ **إضافة رمز لمرة واحدة** رمز QR من ملف صورة أو لقطة شاشة ملصوقة. انظر [إضافة رمز](/ar/docs/features/totp/#إضافة-رمز).
- **مطالبات تسجيل الدخول عبر HTTP** (نافذة اسم المستخدم وكلمة المرور المنبثقة لموقع) تملؤها [إضافة المتصفح](/ar/docs/features/autofill/#نوافذ-تسجيل-الدخول-عبر-http) لا تطبيق سطح المكتب: فالتطبيق لا يعرض المواقع.
- **[Wi-Fi](/ar/docs/features/wifi/):** يحدد الشبكة التي يتصل بها الحاسوب والشبكات في النطاق، ويستورد الشبكات التي حفظها (مع كلمات مرورها حيث يوفرها Windows أو NetworkManager)، ويعرض حفظ شبكة عند انضمامك إليها.
- **[المشاركة](/ar/docs/features/sharing/) و[الوصول في الطوارئ](/ar/docs/features/emergency-access/):** الشاشات نفسها الموجودة في خزنة الويب. انظر [المشاركة في التطبيق](#المشاركة-في-التطبيق).
- **[المؤسسات](/ar/docs/features/organisations/)** (Windows وLinux): شاشات المؤسسة في خزنة الويب، على المحرك نفسه الذي يستخدمه `octapass org`: الأعضاء والمجموعات والخزائن ومراجعة الوصول والسياسات و[تسجيل الدخول الموحّد](/ar/docs/features/single-sign-on/) ورموز [SCIM](/ar/docs/features/scim/). لا يحتويها تطبيق Mac بعد: استخدم هناك خزنة الويب أو سطر الأوامر.
- **البقاء مفتوحًا ما دمت مسجّل الدخول** (مفعّل افتراضيًا، الإعدادات ← التحقق بالجهاز): يُفتح التطبيق مفتوحًا ما دمت مسجّل الدخول إلى الحاسوب، ويحفظ مفتاحه في حماية البيانات في Windows أو حلقة مفاتيح النظام (Linux). لا مؤقت قفل، ولا تسأل التعبئة ولا إظهار سر أو نسخه. وفي Linux دون حلقة مفاتيح عاملة يُقفل كالمعتاد. انظر [البقاء مفتوحًا](/ar/docs/features/biometric-unlock/).
- **فتح المتصفح:** يعمل التطبيق كمضيف رسائل أصلي (native messaging host)، فتستطيع [إضافة المتصفح](/ar/docs/platforms/browser-extension/) الفتح بـ Windows Hello أو polkit ومشاركة جلسة فتح واحدة. وما دام التطبيق يبقى مفتوحًا، تُفتح الإضافة عن طريقه دون سؤال.
- **[وكيل SSH](/ar/docs/features/ssh-keys/#وكيل-ssh):** يقدّم مفاتيح SSH من خزنتك إلى `ssh` وGit وبيئات التطوير، ويسألك مرة واحدة ثم لا يسأل مجددًا لمدة 15 دقيقة أو حتى تُقفل الخزنة. يبقى متوقفًا حتى تشغّله من الإعدادات. ويقرأ محرر المفاتيح أيضًا المفاتيح من `~/.ssh` ويكتبها إليه.
- **[أداة سطر الأوامر تتبع التطبيق](/ar/docs/platforms/cli/#استخدام-حساب-تطبيق-سطح-المكتب):** يستخدم `octapass` حساب التطبيق دون تسجيل دخول، ويكون مفتوح القفل كلما كان التطبيق مفتوحًا. وما دام التطبيق مقفلًا، يطلب الأمر Windows Hello أو polkit. وقفل التطبيق يقفلها أيضًا.

- **[مفاتيح المرور في Windows 11](/ar/docs/features/passkeys/):** مزوّد مفاتيح مرور لنظام Windows، متوقف افتراضيًا. يحتاج إلى حزمة MSIX، ويطلب Windows Hello لكل مفتاح مرور، ولم يُجرَّب على Windows حقيقي بعد.

## دون حساب

**الاستخدام على هذا الجهاز فقط**، في الشاشة الأولى، يحفظ خزنة على هذا الحاسوب بلا حساب. راجع [الاستخدام دون حساب](/ar/docs/features/local-vault/) للنسخ الاحتياطية والخزنات المتعددة و**تشغيل المزامنة**.

ينطبق **السؤال عند كل تعبئة** (الإعدادات ← التحقق بالجهاز) حين يكون **البقاء مفتوحًا** متوقفًا، ويحدد ما إذا كانت الكتابة التلقائية تطلب Windows Hello أو كلمة مرور نظامك في كل مرة. وعند إيقافه تملأ مباشرة ما دامت الخزنة مفتوحة؛ والخزنة المقفلة تسأل دائمًا. والحاسوب الذي لا قفل فيه يستطيع Octa Pass استخدامه يملأ دون مطالبة ما دامت الخزنة مفتوحة، ويطلب كلمة المرور الرئيسية بعد إعادة التشغيل أو القفل. ولا يشمل هذا المفتاح النسخ من الوصول السريع بعد.

## المشاركة في التطبيق

تحت **المشاركة** تستطيع إنشاء خزنات مشتركة، وإضافة أشخاص بعد مقارنة بصمتهم، وتغيير دورهم وإزالتهم، وإدارة عائلة، وإنشاء روابط مشاركة لمرة واحدة، واختيار جهات اتصال الطوارئ. وتسرد **الإعدادات** أجهزتك المسجّل الدخول عليها وسجل الأمان.

كل شيء يتم في عملية التطبيق نفسها، لا في نافذته: تُختم مفاتيح الخزنة لكل شخص وتُوقَّع هناك، وتحصل خزنة عضو أُزيل على مفتاح جديد هناك، ويفتح مفتاح طوارئ أُفرج عنه خزنات الشخص الآخر هناك، للقراءة فقط. والبصمات التي تقارنها تُحسب من المفاتيح التي أعادها الخادم، فلو بدّل الخادم مفاتيح أحدهم لظهرت بصمة مختلفة، ويظهر عضو تغيّرت مفاتيحه بعد مقارنتك له على أنه غير موثَّق مرة أخرى.

يُفتح رابط المشاركة المنشأ في التطبيق في خزنة الويب المستضافة، أو، على خادم مستضاف ذاتيًا، في خزنة الويب التي يقدّمها ذلك الخادم (يذكر الرابط اسم الخادم). والمفتاح موجود فقط في الجزء الذي بعد `#`، الذي لا ترسله المتصفحات أبدًا.

## التشغيل في الخلفية

إغلاق نافذة الخزنة لا يُنهي Octa Pass، بل يبقى عاملًا، فيستمر عمل الوصول السريع والكتابة التلقائية وإضافة المتصفح ووكيل SSH وواجهة سطر الأوامر. ولا يتغير القفل: حين يكون **البقاء مفتوحًا** متوقفًا تُقفل الخزنة حسب مؤقت القفل التلقائي سواء كانت النافذة مفتوحة أم لا؛ وما دام مفعّلًا فلا مؤقت.

- **الأيقونة:** في أيقونة Octa Pass في علبة النظام الأوامر **إظهار Octa Pass** و**الوصول السريع** و**قفل** (ما دامت الخزنة مفتوحة) و**إنهاء Octa Pass**. وفي Windows يُظهر النقر على الأيقونة نافذة الخزنة. ولا يعرض GNOME أيقونات علبة النظام إلا مع إضافة AppIndicator، وهي مضمّنة في Ubuntu.
- **الفتح عند تسجيل الدخول:** يبدأ Octa Pass عند تسجيل دخولك إلى الحاسوب، في الخلفية والخزنة مقفلة، دون نافذته. وفتحه مرة أخرى من قائمة ابدأ أو من مشغّل التطبيقات يُظهر نافذة النسخة العاملة، ولا يبدأ نسخة ثانية أبدًا.
- **الإنهاء:** **إنهاء Octa Pass** في قائمة الأيقونة، أو ملف ← إنهاء في Windows، أو الخزنة ← إنهاء Octa Pass في Linux.
- **بعد الإنهاء القسري أو التعطّل:** يعود Octa Pass إلى العمل وحده بعد ثانيتين تقريبًا، في الخلفية: ترجع الأيقونة إلى علبة النظام، وتبقى النافذة مغلقة والخزنة مقفلة (ما لم تكن باقية مفتوحة). ولا يوقفه إلا إنهاؤه بإحدى الطرق السابقة، حتى تسجّل الدخول مرة أخرى أو تفتحه بنفسك. وإن توقّف ثلاث مرات متتالية خلال دقيقتين من بدئه، لا يُعاد تشغيله. وهذا في النسخ التي تبنيها للإصدار، لا في نسخة التطوير.

كلاهما مُشغَّل افتراضيًا. أوقف أيًّا منهما من **الإعدادات ← التشغيل في الخلفية**، والاختيار لهذا الحاسوب فقط. والفتح عند تسجيل الدخول مُدرَج في قائمة النظام نفسها، لذا يمكنك إيقافه من هناك أيضًا:

| نظام التشغيل | أين يُدرجه النظام |
|---|---|
| Windows | مدير المهام ← تطبيقات بدء التشغيل، أو الإعدادات ← التطبيقات ← بدء التشغيل |
| Linux | تطبيقات بدء التشغيل في سطح المكتب لديك (الملف هو `~/.config/autostart/app.octap.desktop.desktop`) |

يُشغّل Octa Pass الفتح عند تسجيل الدخول في أول مرة تبدأ فيها نسخة مثبّتة. وإن أوقفته، هنا أو في النظام، يبقى متوقفًا. وإن نقلت التطبيق لاحقًا، يتبعه الإدخال في المرة التالية التي يبدأ فيها Octa Pass.

وعلى Mac يُعرض **الإعدادات ← التشغيل في الخلفية ← الفتح عند تسجيل الدخول إلى هذا الحاسوب** متى كان Octa Pass في مجلد التطبيقات. ويُدرجه macOS في إعدادات النظام ← عام ← عناصر تسجيل الدخول.

وعلى Mac تتبع أيقونة شريط القائمة الخيار **الإعدادات ← التشغيل في الخلفية ← إظهار الأيقونة في شريط القائمة**. فإن سحبتها خارج شريط القائمة مع ⌘ تعود في المرة التالية التي يبدأ فيها Octa Pass، وأوقف الخيار لتُبعدها. ويستطيع macOS 26 أيضًا إخفاءها من إعدادات النظام ← شريط القائمة ← السماح في شريط القائمة، حيث تظهر تحت Octa Pass أو تحت الطرفية أو بيئة التطوير التي شغّلت Octa Pass.

ويعود تطبيق Mac أيضًا بعد الإنهاء القسري أو التعطّل، أيًّا كانت طريقة فتحه: بأيقونة شريط القائمة دون نافذة، ودون أن يأخذ التركيز من التطبيق الذي تعمل فيه (وتدل أيقونته في Dock على أنه يعمل، كما حين يُفتح عند تسجيل الدخول). ويتولى ذلك مساعد صغير داخل التطبيق اسمه **Octa Pass Watchdog**: يعمل ما دام Octa Pass يعمل، بلا نافذة ولا وصول إلى خزنتك ولا اتصال بالشبكة، وستراه في مراقب النشاط. وأي إنهاء عادي يوقفهما معًا: **إنهاء Octa Pass** في قائمة أيقونة شريط القائمة، أو **Cmd+Q**، أو «إنهاء» في Dock، أو تسجيل الخروج. أما «فرض الإنهاء» (أو `kill -9`) والتعطّل فلا يُحسبان، فيعود Octa Pass إلى العمل، ثلاث مرات على الأكثر في دقيقتين.

## الكتابة التلقائية

تكتب الكتابة التلقائية بيانات دخول في نافذة تطبيق آخر، للتطبيقات التي لا تصل إليها إضافة المتصفح. وهي في تطبيق Windows وLinux، وليست في تطبيق Mac بعد.

- **من الوصول السريع:** افتحه بـ **Ctrl+Shift+Space**، واختر بيانات دخول واضغط **Ctrl+Enter**، أو انقر زر لوحة المفاتيح الخاص بها. يعود Octa Pass إلى النافذة التي كنت فيها ويكتب هناك.
- **باختصار الكتابة التلقائية:** في التطبيق الذي تريد تسجيل الدخول إليه، اضغط `Ctrl+Shift+\`. إذا كانت بيانات دخول واحدة تخص تلك النافذة، يكتبها Octa Pass. وإذا لم توجد أي بيانات أو وُجدت عدة بيانات، يُفتح الوصول السريع ببيانات الدخول المطابقة؛ اضغط Enter لكتابة إحداها.

افتراضيًا يكتب Octa Pass اسم المستخدم، ثم Tab، ثم كلمة المرور، ثم Enter. وعناصر كلمات المرور تكتب كلمة المرور ثم Enter. تستطيع تغيير ما يُكتب في قسم **الكتابة التلقائية** في العنصر، باستخدام `{USERNAME}` و`{PASSWORD}` و`{TOTP}` (الرمز لمرة واحدة الحالي) و`{TAB}` و`{ENTER}` و`{DELAY 500}` (انتظر 500 ميلي ثانية، للتطبيقات البطيئة). أما النص الآخر فيُكتب كما هو.

لا يكتب Octa Pass إلا في نافذة تخص بيانات الدخول:

- **في متصفح،** يجب أن تكون الصفحة على أحد مواقع بيانات الدخول، مطابقةً [مثل الملء التلقائي](/ar/docs/features/autofill/#مطابقة-النطاقات). لا تُعتمد عناوين الصفحات، لأن صفحة تصيّد تستطيع نسخها. ولا يخبر Windows وLinux تطبيقَ Octa Pass بعنوان الصفحة، فأضف النافذة إلى نوافذ الكتابة التلقائية لبيانات الدخول بدلًا من ذلك، أو استخدم [إضافة المتصفح](/ar/docs/platforms/browser-extension/).
- **في التطبيقات الأخرى،** يجب أن يحتوي عنوان النافذة أو اسم التطبيق على عنوان بيانات الدخول، أو على اسم موقعها (`slack` لـ slack.com).
- **نوافذ الكتابة التلقائية** التي تسردها في بيانات الدخول تُعتمد دائمًا. قاعدة مثل `Slack` تطابق أي نافذة يحتوي عنوانها أو اسم تطبيقها عليها؛ وترمز `*` إلى أي نص، كما في `*Remote Desktop*`.

لا يكتب أبدًا في Octa Pass نفسه ولا والشاشة مقفلة، وينتظر حتى ترفع يدك عن مفاتيح الاختصار، ويتوقف إذا أخذت نافذة أخرى التركيز أثناء الكتابة. والأحرف غير الموجودة على لوحة مفاتيحك، مثل `é` أو `ب`، تُكتب أيضًا.

| نظام التشغيل | كيف يكتب | ما تحتاج إليه |
|---|---|---|
| Windows | `SendInput` | لا شيء. لا يسمح Windows للتطبيقات بالكتابة في تطبيقات تعمل بصلاحيات المسؤول. |
| Linux (X11) | XTest | لا شيء |
| Linux (Wayland) | بوابة RemoteDesktop | اسمح لـ Octa Pass في مربع حوار سطح المكتب، مرة واحدة عند كل تشغيل لـ Octa Pass. لا يخبر Wayland أي نافذة مركَّز عليها، فلا تُكتب إلا بيانات دخول تختارها في الوصول السريع، ويفتح اختصار الكتابة التلقائية الوصول السريع. وبدون البوابة ينسخ Octa Pass كلمة المرور بدلًا من ذلك ويمسح الحافظة بعد 30 ثانية. |

## الملء التلقائي في macOS

هذا القسم والقسمان التاليان عن [تطبيق Mac](#تطبيق-mac).

في macOS 14 وما بعده يملأ Octa Pass كلمات المرور ومفاتيح المرور في Safari وتطبيقات أخرى عبر الملء التلقائي للنظام، والرموز لمرة واحدة في macOS 15. فعّله في إعدادات النظام ← عام ← الملء التلقائي وكلمات السر ← **الملء التلقائي من** (في macOS 14: كلمات السر ← خيارات كلمات السر). إن لم يظهر Octa Pass في تلك القائمة، فانقل التطبيق إلى مجلد التطبيقات وافتحه مرة واحدة. ويشغّله أيضًا **الإعدادات ← الملء التلقائي** في التطبيق (وفي macOS 15 يسأل في مكانه). والنسخة التي تبنيها بنفسك يجب أن يوقّعها فريق مطوّرين لدى Apple (انظر [بناء التطبيقات](/ar/docs/contributing/development-setup/#بناء-التطبيقات))؛ ويستخدم `pnpm build:macos` الفريق الذي توقّع به نسخ iPhone.

تعمل إضافة الملء التلقائي كما على iPhone: تفتح الخزنة التي يحفظها التطبيق على جهاز Mac هذا، فتملأ حتى والتطبيق مغلق، ولا تستخدم الشبكة أبدًا. وتطلب Touch ID أو كلمة مرور جهاز Mac أو كلمة المرور الرئيسية، أو لا شيء ما دام **البقاء مفتوحًا** مفعّلًا. ولا تحصل إلا على كلمة المرور أو الرمز أو مفتاح المرور الذي اخترته. وتُحفظ مفاتيح المرور الجديدة في خزنتك قبل أن يحصل عليها الموقع.

### إعداد الرموز لمرة واحدة على Mac

في macOS 15 وما بعده يمكن أن يكون Octa Pass التطبيق الذي يفتح روابط إعداد الرموز لمرة واحدة (`otpauth://`) ورموز QR الخاصة بها. في إعدادات النظام ← عام ← الملء التلقائي وكلمات السر ← **إعداد الرموز في**، اختر **Octa Pass**. بعد ذلك يفتح رابط "إعداد تطبيق المصادقة" في أي موقع Octa Pass، وكذلك تصديرات Google Authenticator (`otpauth-migration://`).

يسأل Octa Pass قبل أن يضيف أي شيء، لأن أي موقع يستطيع فتح رابط كهذا، وإن كانت الخزنة مقفلة يطلب منك فتحها أولًا. ثم تختار أين يذهب كل رمز، كما مع رمز QR ممسوح: الرمز الذي يطابق بيانات دخول ينضم إليها، وبالنسبة إلى غيره تبحث في بيانات دخولك أو تحتفظ بالرمز عنصرًا مستقلًا (انظر [ربط رمز ببيانات دخول](/ar/docs/features/totp/#ربط-رمز-ببيانات-دخول)). والروابط المتعددة التي تُفتح معًا، مثل أجزاء تصدير Google Authenticator، تُراجَع معًا. ثم يعرضه الملء التلقائي في حقول رموز التحقق.

### الانتقال من مدير كلمات مرور آخر على Mac

في macOS 26 تستطيع مديرات كلمات المرور أن تسلّم عناصرها بعضها لبعض مباشرة عبر تبادل بيانات الاعتماد (Credential Exchange)، بـ[صيغة تبادل بيانات الاعتماد من FIDO](/ar/docs/import-export/from-cxf/)، دون ملف. في التطبيق الآخر (مثلًا **ملف ← تصدير البيانات إلى تطبيق آخر** في تطبيق كلمات السر)، اختر **Octa Pass**. يظهر Octa Pass في المقدمة، ويطلب منك فتح قفله إن كان مقفلًا، ويعرض عدد العناصر التي أرسلها التطبيق. لا يُحفظ شيء حتى تختار **استيراد**، وتذهب العناصر إلى خزنتك الشخصية. وإن ألغيت أو أقفلت Octa Pass تُنسى.

إن قال التطبيق الآخر إنه لا يوجد تطبيق يستقبل بياناتك، فافتح Octa Pass مرة واحدة من مجلد التطبيقات ليعرفه macOS.

## المتصفحات المدعومة

تستطيع إضافة المتصفح الفتح عبر التطبيق في هذه المتصفحات، المثبّتة من صانعيها:

- Google Chrome (وBeta وDev وCanary)
- Microsoft Edge (كل القنوات)
- Brave (كل القنوات)
- Firefox (كل القنوات)
- Vivaldi
- Opera
- Arc

يتحقق التطبيق من البرنامج الذي يسأل قبل أن يجيب: لا يقبل إلا `octapass-native-host` الذي داخل التطبيق، موقّعًا من فريق المطوّرين نفسه، ومشغَّلًا من أحد هذه المتصفحات. في Mac وWindows يجب أن يحمل المتصفح توقيع شيفرة صانعه؛ وفي Linux يجب أن يكون مثبّتًا على مستوى النظام (مملوكًا للمستخدم الجذر root)، فالمتصفحات المثبّتة في مجلدك الرئيسي ومتصفحات Snap أو Flatpak غير مقبولة. وChromium بلا توقيع صانع، فهو غير مقبول في Mac وWindows.

في أي متصفح آخر تقول الإضافة *The Octa Pass app doesn't recognise this browser, so it can't unlock it*. افتح هناك بكلمة مرورك الرئيسية بدلًا من ذلك. أما إضافة Safari فلا تستطيع الوصول إلى التطبيق إطلاقًا (انظر [Safari](/ar/docs/platforms/browser-extension/#safari)).

## الحصول على الإضافة

إلى أن تصل إضافة Octa Pass إلى التطبيق، تعرضها بطاقة صغيرة في أسفل الشريط الجانبي لنافذة الخزنة: **املأ كلمات المرور في متصفحك**، مع رابط **احصل عليها في …** لكل متصفح على هذا الحاسوب تستطيع الإضافة الاتصال منه (Chrome وEdge وBrave وChromium وFirefox). في Mac يُفتح كل رابط في ذلك المتصفح نفسه، وكذلك في Linux حين يمكن تشغيل المتصفح باسمه، أما في Windows فيُفتح في متصفحك الافتراضي. وإن لم تكن المتصفحات مربوطة بعد، ففي البطاقة أيضًا **لديك الإضافة؟ اربطها**.

- **كيف يعرف التطبيق:** أول مرة تسأل فيها إضافة Octa Pass التطبيقَ عن أي شيء، يسجّل التطبيق المتصفح الذي جاءت منه، في `browser-extension.json` داخل مجلد بياناته (حاوية App Group في Mac). ما يُسجَّل هو اسم المتصفح والتاريخ، لهذا الحاسوب فقط: لا يُزامَن، ولا أسرار فيه. تطبيق Mac يعمل في بيئة معزولة (sandbox) ولا يستطيع النظر في ملفات تعريف المتصفحات، فبهذا يعرف.
- **الربط بدلًا من ذلك:** إن كانت الإضافة قد وصلت من قبل ولكن لا متصفح مربوط الآن (بعد **فصل إضافة المتصفح** مثلًا)، تقول البطاقة **اربط إضافة المتصفح** بدلًا من ذلك.
- **إغلاقها:** زر × يُخفي البطاقة على هذا الحاسوب. وفي **الإعدادات ← إضافة المتصفح** الروابط نفسها دائمًا، ومعها المتصفحات المربوطة والمتصفحات التي وصلت منها الإضافة، وزرّا **ربط** و**فصل** (في Windows وLinux أيضًا، إلى جانب قائمة «المتصفح»). وفي Mac فيها كذلك رابط [إضافة Safari](/ar/docs/platforms/browser-extension/#safari)، التي تأتي في تطبيق Octa Pass خاص بها.

يفتح كل رابط صفحة الإضافة في متجرها: Chrome Web Store لـ Chrome وBrave وChromium، وFirefox Add-ons لـ Firefox. ويحصل Edge أيضًا على صفحة Chrome Web Store إلى أن تصل الإضافة إلى Edge Add-ons. انظر [إضافة المتصفح](/ar/docs/platforms/browser-extension/#التثبيت).

## التحديثات

لا يوجد تحديث تلقائي بعد: ثبّت بناءً جديدًا فوق القديم. التحديثات الموقّعة داخل التطبيق ومستودعات الحزم على Linux مخطط لها في 1.0.

## كلمة المرور الرئيسية

**الإعدادات ← الأمان ← كلمة المرور الرئيسية** تغيّرها: أدخل كلمة المرور الحالية والجديدة. يبقى مفتاحك السري ورمز الاسترداد كما هما، وتُسجَّل أجهزتك الأخرى خروجها، ويجب تفعيل الفتح بـ Touch ID أو Windows Hello أو polkit من جديد.

هل غيّرتها على جهاز آخر؟ على Mac، افتح القفل بكلمة المرور الجديدة: يسجّل التطبيق دخوله من جديد وحده، دون أن تسجّل الخروج أولًا. ولا تعود كلمة المرور القديمة تفتحه ما دام Mac متصلًا بالإنترنت.

نسيتها؟ **هل نسيت كلمة المرور الرئيسية؟** في شاشتي تسجيل الدخول والقفل تعيد تعيينها برمز الاسترداد من [مجموعة الاسترداد](/ar/docs/getting-started/recovery-kit/): نرسل إليك رمزًا بالبريد الإلكتروني، ثم تدخل رمز الاسترداد وكلمة مرور جديدة وتحفظ مجموعة الاسترداد الجديدة. انظر [استرداد الحساب](/ar/docs/security/account-recovery/).
