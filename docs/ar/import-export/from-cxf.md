:::note[قيد التطوير]
يعمل استيراد CXF وتصديره في خزنة الويب وإضافة المتصفح وتطبيقي سطح المكتب والهاتف و[واجهة سطر الأوامر](/ar/docs/platforms/cli/) (`octapass import cxf`). تُقرأ كل البيانات على جهازك.
:::

[صيغة تبادل بيانات الاعتماد](https://fidoalliance.org/specs/cx/cxf-v1.0-ps-errata-20260309.html) (CXF) هي معيار تحالف FIDO لنقل كلمات المرور ومفاتيح المرور بين التطبيقات. يقرأ Octa Pass الإصدار 1.0 من CXF ويكتبه كملف JSON. استورد ملف CXF من تطبيق آخر بصيغة **تبادل بيانات الاعتماد (CXF)**، أو [صدِّر ملفًا](/ar/docs/import-export/export/) للانتقال إلى تطبيق آخر.

تستطيع التطبيقات أيضًا تسليم CXF بعضها لبعض مباشرة، بلا ملف: على Android (راجع [الانتقال بين مديري كلمات المرور على Android](/ar/docs/platforms/mobile/#الانتقال-بين-مديري-كلمات-المرور-على-android))، وعلى iOS 26، وعلى macOS 26 (راجع [الانتقال من مدير كلمات مرور آخر على Mac](/ar/docs/platforms/desktop/#الانتقال-من-مدير-كلمات-مرور-آخر-على-mac)). يعرض Octa Pass ما أرسله التطبيق الآخر قبل حفظ أي شيء.

## ما ينتقل

| CXF | Octa Pass |
|---|---|
| `basic-auth`، مع مواقع العنصر وتطبيقات Android | بيانات دخول |
| `passkey` (مفاتيح P-256 وEd25519) | مفتاح مرور في بيانات الدخول، جاهز لتسجيل الدخول |
| `totp` | الرمز لمرة واحدة في بيانات الدخول |
| `note` | الملاحظات |
| `credit-card` | بطاقة |
| `person-name` و`address` و`identity-document` و`passport` و`drivers-license` | هوية، مع تفاصيل المستند في ملاحظاتها |
| `api-key` | بيانات دخول (المفتاح ككلمة المرور) |
| `generated-password` | كلمة مرور |
| `wifi` | ملاحظة آمنة |
| `ssh-key` | مفتاح SSH، حين يمكن قراءة مفتاحه الخاص (OpenSSH أو PEM أو PKCS#8)؛ ويُحفظ حقل مخصص `Passphrase` للتصدير. مفاتيح PuTTY وDSA وFIDO لا يمكن تحويلها، لذلك تصير هذه العناصر ملاحظات آمنة. |
| `custom-fields` | حقول مخصصة في بيانات الدخول، أو أسطر في الملاحظات |
| المجموعات | الوسوم |
| `id` العنصر | يُحفظ مع العنصر، فيحدّثه استيراد الملف مرة أخرى |
| `creationAt` و`modifiedAt` للعنصر | تاريخا الإنشاء وآخر تغيير |
| `favorite` للعنصر | مفضّل |

العنصر الذي فيه بيانات دخول وبطاقة يصير عنصرين. تُترك الحقول الفارغة.

حين يصدّر Octa Pass بصيغة CXF، يحمل العنصر القادم من تطبيق آخر تاريخي إنشاء ذلك التطبيق وآخر تغيير فيه، فيبقيان بعد الانتقال.

## ما لا ينتقل

- **الملفات.** ملف CXF يسمّي الملفات المرفقة فقط؛ أما الملفات نفسها فتنتقل منفصلة، وهذا لا يقبله Octa Pass بعد (وعلى Android لا يطلبها). يذكر Octa Pass عدد ما تُرك.
- **مفاتيح المرور بمفاتيح RSA.** يوقّع Octa Pass بمفاتيح P-256 وEd25519؛ أما مفاتيح المرور الأخرى فتُتخطّى مع تحذير.
- أنواع بيانات الاعتماد الأحدث من CXF 1.0 تُتخطّى وتُذكر بأسمائها في ملخص الاستيراد. والملف من إصدار رئيسي أحدث من CXF لا يُقرأ.

## ما اختُبر به

يختبر Octa Pass استيراد CXF لديه على المثال الوارد في مواصفة CXF، وعلى ملفات صدّرها Dashlane و1Password (نشرها Bitwarden كملفات اختبار)، ويتحقق من أن تصديراته الخاصة بصيغة CXF تُستورد من جديد.
