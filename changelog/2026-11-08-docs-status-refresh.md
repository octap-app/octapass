---
title: The docs say what's finished
date: 2026-11-08
summary: 46 docs pages moved from "in progress" to beta or stable now that their features are built, and the pages still in progress say exactly what's missing.
tags: [docs]
---

Many docs pages still said "in progress" for features that are built in every app. Each page's claims were checked against the code and the changelog, in English and Arabic:

- **Now beta (built, not released):** every import and export page; attachments, emergency access, environments, masked email, the password generator, recovery info, the security dashboard and two-step sign-in; account recovery and encryption; backups, Docker and the relay; the browser extension and the CLI; and the getting-started pages.
- **Now stable:** the development setup and translation guides, which are about the project itself.
- **Still in progress, with notes that name the gap:** autofill, device unlock, passkeys, sharing, Safes, SSH keys, Wi-Fi, QR codes, sync, single sign-on and organisations, among others. Most of the gaps are in the native Mac app, which replaced the Tauri one on 2026-11-06, or are untested on real hardware.

The [support matrix](/docs/platforms/support-matrix/) is up to date as of today. Nothing is released yet: there's still no public service, no store listing and no external audit, and the pages keep saying so.
