title: The website and docs are in Arabic
date: 2026-11-02
summary: Arabic landing page and docs at /ar/, per-page social images, hreflang links, and the setup for community translations through Weblate.
tags: [website, docs]
---

The landing page and all the docs are now in Arabic, laid out right to left, at [/ar/](/ar/) and [/ar/docs/](/ar/docs/). They use the same words as the Arabic apps. The changelog stays in English.

Every page now has its own social image, drawn at build time, and `hreflang` links between the two languages.

Community translations will run on Weblate. The strings it needs are in `translations/`, and [translations](/docs/contributing/translations/) explains how it works and how to add a language. The Weblate project opens when the repository goes public.
