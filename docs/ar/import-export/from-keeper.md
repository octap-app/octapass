:::note[قيد التطوير]
يعمل مستورِد Keeper في خزنة الويب وإضافة المتصفح وتطبيقي سطح المكتب والهاتف و[واجهة سطر الأوامر](/ar/docs/platforms/cli/) (`octapass import keeper`). تُقرأ كل البيانات على جهازك.
:::

## التصدير من Keeper

1. في Keeper Web Vault أو تطبيق سطح المكتب، افتح **Settings ← Export**.
2. اختر **JSON** (موصى به: يحفظ أنواع السجلات والحقول المنظمة) أو **CSV**.
3. أكّد بكلمة مرورك الرئيسية واحفظ الملف.

تعمل أيضًا ملفات `export --format json` و`export --format csv` من Keeper Commander. أما تصديرا KeePass (`.kdbx`) وPDF فليسا من صيغ Keeper: استورد ملف `.kdbx` بصفته [KeePass](/ar/docs/import-export/from-keepass/) بدلًا من ذلك.

## ما يُستورد

| Keeper | Octa Pass |
|---|---|
| سجلات تسجيل الدخول (العنوان، الدخول، كلمة المرور، الموقع، الملاحظات) | بيانات دخول |
| مواقع إضافية | عناوين URL أخرى في بيانات الدخول |
| الرموز لمرة واحدة (`$oneTimeCode` و`TFC:Keeper`) | TOTP في بيانات الدخول |
| أسئلة الأمان | [أسئلة الأمان](/ar/docs/features/recovery-info/) في بيانات الدخول |
| الحقول المخصصة، والحقول المخفية | حقول مخصصة (تبقى الأسرار مخفية) |
| بطاقات الدفع | بطاقات دفع |
| جهات الاتصال، والعناوين، وبطاقات الهوية، ورخص القيادة، وجوازات السفر، وشهادات الميلاد | هويات، مع أرقام الهوية والتواريخ كأسطر في الملاحظات |
| الملاحظات الآمنة | ملاحظات آمنة |
| سجلات الخادم وقاعدة البيانات وWi-Fi ومفاتيح SSH | بيانات دخول حين يكون فيها اسم مستخدم أو كلمة مرور أو موقع؛ وإلا ملاحظات آمنة. تُحفظ كل الحقول. |
| المجلدات والمجلدات المشتركة | وسوم، مثل `Work\Dev` أو `Family\Shared logins` |
| الملفات المرفقة | ليست في تصديرات Keeper؛ أعد إضافتها يدويًا |

### المعرّفات والتواريخ

| حقل Keeper | في Octa Pass |
|---|---|
| `$record_uid` (CSV من Keeper Commander) | يُحفظ مع العنصر، فيحدّثه استيراد الملف مرة أخرى |
| `uid` (JSON من Keeper Commander) | الأمر نفسه |
| `uid` (JSON من Web Vault) | لا يُحفظ: فـ Web Vault يرقّم السجلات 1 و2 و3 في كل تصدير، فلا يدل الرقم على السجل في المرة التالية |
| `last_modified` (JSON من Keeper Commander، بالثواني بنظام Unix) | تاريخ آخر تغيير |
| `$type` | نوع العنصر (انظر أعلاه) |
| أذونات `shared_folders` | لا تُستورد: فـ Octa Pass يشارك خزنات كاملة بدلًا من ذلك |

لا تاريخ إنشاء ولا سجل كلمات مرور في تصديرات Keeper. لا صف عناوين في ملف CSV: الأعمدة هي المجلد، والعنوان، والدخول، وكلمة المرور، والموقع، والملاحظات، والمجلد المشترك، ثم أزواج اسم الحقل وقيمته. وحين لا معرّفات في الملف، يجد استيراده مرة أخرى بيانات الدخول نفسها بالموقع واسم المستخدم.

تصدير CSV أقل تفصيلًا من JSON: لا أنواع سجلات فيه، فيصير كل صف بيانات دخول، أو ملاحظة آمنة حين لا يحوي سوى ملاحظات. وتُحفظ حقوله المخصصة كما هي.

## الاستيراد إلى Octa Pass

اختر **الاستيراد ← Keeper**، وأسقط الملف، ثم راجع واستورد. يتعرّف Octa Pass على JSON وCSV من تلقاء نفسه. راجع [نظرة عامة على الاستيراد](/ar/docs/import-export/overview/).

احذف ملف التصدير بعد ذلك: فهو غير مشفّر.
