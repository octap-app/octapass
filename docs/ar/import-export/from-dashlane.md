:::note[قيد التطوير]
يعمل مستورِد Dashlane في خزنة الويب وإضافة المتصفح وتطبيقي سطح المكتب والهاتف و[واجهة سطر الأوامر](/ar/docs/platforms/cli/) (`octapass import dashlane`). تُقرأ كل البيانات على جهازك.
:::

## التصدير من Dashlane

1. افتح Dashlane في متصفحك وانتقل إلى **My account ← Settings ← Export data**.
2. اختر **Export to CSV**. ينزّل Dashlane ملف ZIP فيه ملف CSV لكل نوع من العناصر.
3. أبقِ ملف ZIP كما هو. وإن فككت ضغطه فيمكنك استيراد ملفات CSV واحدًا واحدًا.

**الأرشيف الآمن** (`.dash`) في Dashlane غير مدعوم. فحاويته وتشفيره غير موثقين علنًا، ولا يوجد قارئ مستقل مفتوح المصدر يُتحقق من محلّل مقابله؛ وهندسته العكسية تهدد بفقدان عناصر دون إنذار، وقد تنكسر مع أي تحديث من Dashlane. استخدم تصدير CSV (أو تصدير JSON الأقدم) بدلًا منه: فيه كل عنصر يصدّره Dashlane بصيغة مقروءة. كانت تطبيقات Dashlane الأقدم لسطح المكتب تصدّر JSON؛ ويقرؤه Octa Pass أيضًا.

## ما يُستورد

| Dashlane | Octa Pass |
|---|---|
| بيانات الدخول (`credentials.csv`) | بيانات دخول، مع الفئة كوسم. أسماء المستخدم الإضافية تصير حقولًا مخصصة. |
| TOTP (`otpUrl` أو `otpSecret`) | TOTP في بيانات الدخول |
| الملاحظات الآمنة (`securenotes.csv`) | ملاحظات آمنة |
| بطاقات الدفع (`payments.csv`) | بطاقات دفع |
| الحسابات المصرفية (`payments.csv`) | ملاحظات آمنة بكل حقولها |
| المعرّفات: جوازات السفر وبطاقات الهوية والرخص وأرقام الضمان الاجتماعي والضرائب (`ids.csv`) | هويات، مع الرقم والتواريخ في الملاحظات |
| المعلومات الشخصية (`personalInfo.csv`) | هوية واحدة باسمك وبريدك الإلكتروني وهاتفك وعنوانك. وتذهب رسائل البريد والهواتف والعناوين الإضافية إلى ملاحظاتها. |
| الملفات الأخرى في ZIP | تُتخطّى، مع تحذير |
| مفاتيح المرور والمرفقات | ليست في تصدير CSV من Dashlane |

### أعمدة `credentials.csv`

صف العناوين هو `username,username2,username3,title,password,note,url,category,otpUrl` (و`otpSecret` قبل 2024).

| العمود | في Octa Pass |
|---|---|
| `title` و`url` و`username` و`password` و`note` | العنوان والموقع واسم المستخدم وكلمة المرور والملاحظات |
| `username2` و`username3` | الحقلان المخصصان "Username 2" و"Username 3" |
| `category` | وسم |
| `otpUrl` / `otpSecret` | الرمز لمرة واحدة |

لا معرّفات ولا تواريخ في ملفات CSV. استيرادها مرة أخرى يجد بيانات الدخول نفسها بالموقع واسم المستخدم.

### تصدير JSON

| حقل JSON | في Octa Pass |
|---|---|
| `id` | يُحفظ مع العنصر، فيحدّثه استيراد الملف مرة أخرى |
| `creationDatetime` | تاريخ الإنشاء |
| `userModificationDatetime` | تاريخ آخر تغيير |
| `lastUse` | تاريخ آخر استخدام (تقدير مأخوذ من مستورِدات التطبيقات الأخرى: Dashlane لا يوثّق تصدير JSON) |
| `anonId` و`spaceId` و`localeFormat` و`lastBackupTime` | لا تُستورد: هذه من شؤون Dashlane الداخلية |
| `login` و`secondaryLogin` و`email` | الأول هو اسم المستخدم؛ والباقي يصير حقولًا مخصصة |
| `domain` و`password` و`note` و`otpUrl` و`category` | الموقع وكلمة المرور والملاحظات والرمز لمرة واحدة والوسم |
| الحقول الأخرى | حقول مخصصة في بيانات الدخول، وأسطر `Label: value` في ملاحظات العناصر الأخرى |

## الاستيراد إلى Octa Pass

اختر **الاستيراد ← Dashlane**، وأسقط ملف ZIP (أو ملف CSV أو JSON)، ثم راجع واستورد. راجع [نظرة عامة على الاستيراد](/ar/docs/import-export/overview/). احذف ملف التصدير بعد ذلك: فهو غير مشفّر.
