---
title: Generated passwords follow more sites' rules
date: 2026-11-02
summary: The login editor's generator and Android's Autofill suggestion now use the site password rules the browser extension already had.
tags: [core, mobile, desktop]
---

Apple's open password rules dataset used to reach only the browser extension's suggestions. The generator in the login editor now follows the rules of the login's website in every app, and so does the suggested password in Android Autofill. See [Password generator](/docs/features/password-generator/#per-site-rules).
