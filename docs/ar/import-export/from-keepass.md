:::note[قيد التطوير]
يعمل مستورِد KeePass في خزنة الويب وإضافة المتصفح وتطبيقي سطح المكتب والهاتف و[واجهة سطر الأوامر](/ar/docs/platforms/cli/) (`octapass import keepass`). تُقرأ كل البيانات على جهازك.
:::

يستطيع Octa Pass قراءة ملف قاعدة بيانات KeePass مباشرة. يُفك تشفيرها على جهازك؛ ولا يغادره الملف ولا كلمة مروره ولا ملف مفتاحه.

## اختر ما تستورده

- **قاعدة البيانات (`.kdbx`)**: موصى بها. تبقى مشفّرة حتى يفتحها Octa Pass على جهازك، وفيها كل شيء: المجموعات والوسوم والحقول المخصصة والسجل والرموز لمرة واحدة. يعمل KDBX 3.1 وKDBX 4 كلاهما، من KeePass 2 وKeePassXC وKeePassDX وKeepass2Android وتطبيقات أخرى متوافقة.
- **تصدير KeePass XML**: في KeePass 2، **File ← Export ← KeePass XML (2.x)**. المحتوى نفسه الموجود في قاعدة البيانات، لكن بنص غير مشفّر.
- **تصدير CSV**: في KeePassXC، **Database ← Export ← CSV File**. وفي KeePass 2، **File ← Export ← KeePass CSV (1.x)**. يترك CSV الحقول المخصصة والوسوم (في KeePass 2) والسجل، لذلك فضّل قاعدة البيانات.

احذف ملفات التصدير غير المشفّرة بعد انتهاء الاستيراد.

## الاستيراد إلى Octa Pass

اختر **الاستيراد ← KeePass / KeePassXC** وأسقط الملف. بالنسبة لقاعدة البيانات، أدخل كلمة مرورها، أو أضف ملف مفتاحها، أو الاثنين معًا، تمامًا كما تفتحها في KeePass. ثم راجع المعاينة واستورد. راجع [نظرة عامة على الاستيراد](/ar/docs/import-export/overview/).

## ما يُستورد

| KeePass | Octa Pass |
|---|---|
| القيد (العنوان، اسم المستخدم، كلمة المرور، URL، الملاحظات) | بيانات دخول، أو ملاحظة آمنة حين لا يحوي القيد سوى ملاحظات |
| عناوين URL الإضافية (KeePassXC) | عناوين URL أخرى في بيانات الدخول |
| المجموعة | وسم بمسار المجموعة، مثل `Work/Email` |
| الوسوم | الوسوم |
| النصوص المخصصة | حقول مخصصة، مخفية إن كانت محمية في KeePass |
| سجل القيد | سجل كلمات المرور (كلمات المرور السابقة فقط) |
| الرموز لمرة واحدة: TOTP في KeePassXC، وإعدادات TOTP الخاصة بـ KeePass، وKeeOtp وKeeTrayTOTP | TOTP في بيانات الدخول |
| تاريخ الانتهاء | حقل مخصص "Expires" |
| سلة المحذوفات (Recycle Bin) | تُترك |
| المرفقات | لا تُستورد: احفظها من KeePass وأضفها إلى العناصر |
| `UUID` | يُحفظ مع العنصر، فيحدّثه استيراد قاعدة البيانات مرة أخرى |
| `CreationTime` و`LastModificationTime` و`LastAccessTime` | تواريخ الإنشاء وآخر تغيير وآخر استخدام. ويعدّ KeePass فتح القيد استخدامًا له أيضًا |
| الكتابة التلقائية (Auto-Type): التسلسل الافتراضي وعناوين النوافذ | تسلسل [الكتابة التلقائية](/ar/docs/platforms/desktop/#الكتابة-التلقائية) ونوافذها في بيانات الدخول. لا يُحفظ تسلسل النافذة الخاص بها، وتُترك الكتابة التلقائية المعطلة |
| مفاتيح المرور في KeePassXC (`KPEX_PASSKEY_*`) | مفاتيح مرور في بيانات الدخول، تستطيع تسجيل الدخول |
| الأيقونات والألوان و`UsageCount` و`LocationChanged` | لا تُستورد: هذه طريقة عرض KeePass للقيد |

يجلب CSV من KeePassXC (`"Group","Title","Username","Password","URL","Notes","TOTP","Icon","Last Modified","Created"`) تاريخي الإنشاء وآخر تغيير، لكن بلا معرّفات: استيراده مرة أخرى يجد بيانات الدخول نفسها بالموقع واسم المستخدم. أما CSV من KeePass 2 (`Account,Login Name,Password,Web Site,Comments`) فلا تواريخ فيه.

تصير إعدادات HOTP (أي `type=Hotp` في KeeOtp وحقول `HmacOtp-` الخاصة بـ KeePass) [رموزًا معتمدة على عدّاد](/ar/docs/features/totp/#الرموز-المعتمدة-على-عدّاد-hotp)، مع عدّادها. أما رموز Steam فلا يستطيع Octa Pass حسابها بعد؛ وتُحفظ كحقول مخفية، وتخبرك المعاينة أي القيود فيها واحد منها.

## ما لا يمكن استيراده

- قواعد بيانات **YubiKey challenge-response**: أزل YubiKey من بيانات اعتماد قاعدة البيانات في KeePassXC أولًا (ويمكنك إعادة إضافته بعد ذلك).
- قواعد بيانات **KeePass 1 (`.kdb`)**: افتحها في KeePass 2 أو KeePassXC واحفظها بصيغة `.kdbx`.
- **إعدادات اشتقاق المفتاح المتطرفة.** للحفاظ على استجابة جهازك، يرفض Octa Pass قواعد البيانات التي فيها أكثر من 20 مليون جولة AES-KDF، أو التي يستخدم فيها Argon2 أكثر من 1 GiB من الذاكرة أو أكثر من 16 GiB إجمالًا (الذاكرة × التكرارات). خفّض الإعدادات تحت **Database ← Database settings ← Security** (في KeePassXC) أو **File ← Database settings ← Security** (في KeePass)، واحفظ، ثم استورد مرة أخرى. الإعدادات المضبوطة على ثانية واحدة في حاسوب سريع مقبولة، لكنها قد تستغرق دقيقة أو أكثر لتُفتح في خزنة الويب.
- إعدادات الكتابة التلقائية (Auto-Type) والأيقونات والألوان لا مكان لها في Octa Pass وتُتخطّى.
