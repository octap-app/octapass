يعمل مستورِد Bitwarden في خزنة الويب وإضافة المتصفح وتطبيقي سطح المكتب والهاتف و[واجهة سطر الأوامر](/ar/docs/platforms/cli/) (`octapass import bitwarden-json` أو `bitwarden-csv`). تُقرأ كل البيانات على جهازك.

## التصدير من Bitwarden

1. في خزنة الويب من Bitwarden، انتقل إلى **Tools ← Export vault**.
2. اختر صيغة:
   - **.json (Encrypted)** مع خيار *password protected*. هذا موصى به: يبقى الملف مشفّرًا حتى يفك Octa Pass تشفيره على جهازك.
   - **.json**: كامل، لكنه غير مشفّر.
   - **.csv**: بيانات الدخول والملاحظات فقط، دون المعرّفات أو التواريخ أو سجل كلمات المرور الموجودة في JSON.
3. أكّد بكلمة مرورك الرئيسية واحفظ الملف.

الخطوات نفسها تنطبق على Vaultwarden.

## ما يُستورد

الحقول كما تكتبها شيفرة التصدير في Bitwarden نفسها (`CipherExport` في مستودع `clients` الخاص بـ Bitwarden).

| حقل Bitwarden | في Octa Pass |
|---|---|
| `id` | يُحفظ مع العنصر، فيحدّثه استيراد الملف مرة أخرى |
| `creationDate` | تاريخ الإنشاء |
| `revisionDate` | تاريخ آخر تغيير |
| `name` | العنوان |
| `notes` | الملاحظات |
| `favorite` | مفضّل |
| `folderId` | وسم باسم المجلد |
| `collectionIds` (تصدير المؤسسات) | وسوم بأسماء المجموعات |
| `fields` (نص، مخفي، مربع اختيار) | حقول مخصصة بالأسماء نفسها. تبقى الحقول المخفية مخفية. أما الحقول المرتبطة فتشير إلى حقل آخر فقط، لذلك تُترك |
| `passwordHistory` | سجل كلمات المرور، لكل منها تاريخ آخر استخدام |
| `reprompt` | لا يُستورد: ليس في Octa Pass طلب كلمة المرور الرئيسية لكل عنصر |
| **بيانات الدخول** `username` و`password` و`totp` | اسم المستخدم وكلمة المرور والرمز لمرة واحدة |
| `uris` مع `match` | المواقع، لكل منها قاعدة المطابقة: يصير *base domain* هو *كل أجزاء هذا النطاق*، ويصير *exact* هو *starts with*، وبلا قاعدة (الافتراضي في Bitwarden) تُتّبع [القاعدة الافتراضية في Octa Pass](/ar/docs/features/autofill/#مطابقة-النطاقات) |
| `passwordRevisionDate` | تاريخ تغيير كلمة المرور، حيث يحويه التصدير (تقدير: لا تكتبه كل إصدارات Bitwarden) |
| `fido2Credentials` | مفاتيح المرور، مع تاريخ إنشائها. تُحفظ لكنها لا تستطيع تسجيل الدخول بعد |
| **البطاقة** | بطاقة دفع: حامل البطاقة، الرقم، تاريخ الانتهاء، رمز الأمان، الشبكة |
| **الهوية** | هوية: الاسم، البريد الإلكتروني، الهاتف، العنوان. أما اللقب والشركة واسم المستخدم ورقم الضمان الاجتماعي وأرقام جواز السفر والرخصة فتذهب إلى الملاحظات كأسطر `Label: value` |
| **ملاحظة آمنة** | ملاحظة آمنة |
| **مفتاح SSH** | ملاحظة آمنة فيها المفتاح العام والبصمة والمفتاح الخاص |
| المرفقات | ليست في تصدير Bitwarden. أضفها من جديد بعد الاستيراد |

### تصدير CSV

يحوي CSV من Bitwarden بيانات الدخول والملاحظات الآمنة فقط. صف عناوينه هو `folder,favorite,type,name,notes,fields,reprompt,archivedDate,login_uri,login_username,login_password,login_totp`؛ وفي تصدير المؤسسات `collections` بدل `folder` و`favorite`.

| عمود CSV | في Octa Pass |
|---|---|
| `type` | بيانات دخول، أو ملاحظة آمنة حين يكون `note` |
| `name` و`notes` | العنوان والملاحظات |
| `folder` و`collections` | الوسوم (تُقسَّم المجموعات عند الفواصل) |
| `favorite` | مفضّل |
| `archivedDate` | وسم باسم `archived`، مع تحذير |
| `fields` | حقول مخصصة. كل سطر هو `Name: value`؛ والسطر الذي لا يحوي `: ` يكمل القيمة التي فوقه، والحقل بلا قيمة يُكتب `null`. تُخفى الحقول التي يوحي اسمها بأنها سر. |
| `login_uri` | المواقع، تُقسَّم عند الفواصل |
| `login_username` و`login_password` و`login_totp` | اسم المستخدم وكلمة المرور والرمز لمرة واحدة |
| `reprompt` | لا يُستورد: ليس في Octa Pass طلب كلمة المرور الرئيسية لكل عنصر |
| صفوف بيانات الدخول الفارغة | تُتخطّى |

لا معرّفات ولا تواريخ في CSV، لذلك يعتمد استيراده مرة أخرى على مطابقة المكرر: الموقع واسم المستخدم نفسيهما، أو العنوان نفسه للملاحظة. استخدم تصدير JSON إن أردت معرّفات العناصر وتواريخ الإنشاء وسجل كلمات المرور.

## الاستيراد إلى Octa Pass

اختر **الاستيراد ← Bitwarden**، وأسقط الملف، وأدخل كلمة مرور التصدير إن كان محميًا، ثم راجع واستورد. راجع [نظرة عامة على الاستيراد](/ar/docs/import-export/overview/).
