---
title: Confirm before filling a card's security code
date: 2026-11-02
summary: A new extension setting asks you to confirm it's you before a card's security code goes into a page.
tags: [extension, security]
---

**Settings → Device auth → Ask before filling a security code** asks for your device unlock or master password before a card's security code is filled, even when filling doesn't otherwise ask. If you say no, the rest of the card is still filled. It's off by default and applies to this browser only.
