---
title: Sort and group your item lists
date: 2026-10-24
summary: Item lists can be grouped by type, first letter or vault and sorted by name or date, from one Sort and group menu. All items now starts grouped by type.
tags: [web, extension, desktop, mobile]
---

Long lists were one flat run of titles. Now **All items** starts in sections by type (Logins, Passwords, Cards, Identities, Secure notes, Documents), each with a header and a count that stay in view while you scroll.

The new **Sort and group** menu at the top of each list changes that:

- **Sort by** name (A to Z or Z to A), date added (newest or oldest first) or last changed. Names sort the way your app language does, and "Item 2" comes before "Item 10".
- **Group by** type, first letter (Latin letters, Arabic letters, then # for digits and symbols), vault (when you have several) or nothing.

Each list remembers its own choice on each device; it isn't synced. A list of one type, such as Logins, starts grouped by first letter. Search results stay ungrouped in name order, the trash keeps the latest deletions first, and the extension's **This site** view keeps the best matches first.

It works the same in the web vault, the desktop and phone apps and the browser extension, in English and Arabic. See [sorting and grouping](/docs/features/sorting-and-grouping/).
