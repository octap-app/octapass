| المصطلح | المعنى |
|---|---|
| **Account Symmetric Key (ASK)** | مفتاح عشوائي بطول 256 بت يفتح مفاتيحك الخاصة ومفاتيح خزنتك الشخصية. يُخزَّن على الخادم بصيغة ملفوفة (مشفّرة) فقط. |
| **Account Unlock Key (AUK)** | المفتاح المشتق من كلمة مرورك الرئيسية ومفتاحك السري. وهو يفك التفاف ASK. |
| **MIT** | رخصة MIT، رخصة مفتوحة المصدر قصيرة ومتساهلة. يُنشر Octa Pass بموجبها. |
| **Argon2id** | دالة تجزئة لكلمات المرور تستهلك الذاكرة، تجعل تخمين كلمات المرور الرئيسية بطيئًا ومكلفًا. |
| **البيانات المرتبطة (Associated data)** | سياق غير مشفّر مرتبط بنص مشفَّر. يفشل فك التشفير إذا نُقل النص المشفَّر إلى مكان آخر. |
| **الكتابة التلقائية (Auto-type)** | كتابة اسم المستخدم وكلمة المرور في التطبيق المُركَّز عليه بضغطات مفاتيح محاكاة، وتُستخدم حيث لا توجد واجهة ملء تلقائي. |
| **CXF / CXP** | صيغة وبروتوكول تبادل بيانات الاعتماد من FIDO Alliance: معياران لنقل كلمات المرور ومفاتيح المرور بين المديرين. |
| **الوصول في الطوارئ** | السماح لجهة اتصال موثوقة بالوصول إلى خزنتك بعد مدة انتظار تتحكم فيها. |
| **مفتاح العنصر (Item key)** | مفتاح عشوائي لعنصر واحد، يلفّه مفتاح خزنته. |
| **k-anonymity** | إرسال بادئة تجزئة قصيرة فقط تطابق عدة مدخلات، فلا يستطيع الخادم معرفة أيها تفحص. |
| **البريد المُقنَّع** | اسم مستعار لإعادة التوجيه يُخفي بريدك الإلكتروني الحقيقي عن موقع. |
| **كلمة المرور الرئيسية** | كلمة المرور التي تتذكرها. لا تُرسَل إلى الخادم أبدًا. |
| **OPAQUE** | تبادل مفاتيح موثّق بكلمة مرور (RFC 9807) يتيح لك تسجيل الدخول دون أن يعرف الخادم كلمة مرورك أبدًا. |
| **مفتاح المرور** | زوج مفاتيح WebAuthn يحل محل كلمة المرور لموقع واحد. ولا يمكن التصيّد به. |
| **امتداد PRF** | امتداد في WebAuthn يتيح لمفتاح مرور إنتاج سر، يمكن استخدامه لفتح خزنة. |
| **Public Suffix List (PSL)** | قائمة بلواحق النطاقات (مثل `co.uk`) تُستخدم لتحديد النطاق القابل للتسجيل لموقع من أجل مطابقة آمنة. |
| **رمز الاسترداد** | مفتاح بطول 256 بت يظهر مرة واحدة عند التسجيل، يمكنه استعادة الوصول إذا نسيت كلمة مرورك الرئيسية. |
| **مجموعة الاسترداد** | ملف PDF يُنشأ على جهازك يحوي مفتاحك السري ورمز الاسترداد وتفاصيل الحساب. |
| **خريطة الاسترداد** | عرض يجمّع حساباتك حسب البريد الإلكتروني أو الهاتف القادر على إعادة تعيينها. |
| **المفتاح السري** | مفتاح عشوائي بطول 128 بت (`OP1-…`) يُدمج مع كلمة مرورك الرئيسية. لا يُرسَل إلى الخادم أبدًا. |
| **TOTP** | كلمات مرور لمرة واحدة قائمة على الوقت (RFC 6238): الرموز المكوّنة من 6 أرقام من تطبيقات المصادقة. |
| **مفتاح الخزنة (Vault key)** | مفتاح عشوائي لخزنة، ملفوف لكل عضو له حق الوصول. |
| **XChaCha20-Poly1305** | خوارزمية التشفير الموثَّق التي يستخدمها Octa Pass لكل بيانات الخزنة. |
| **انعدام المعرفة** | تصميم لا يستطيع فيه مزوّد الخدمة قراءة بياناتك، لأنك وحدك تملك المفاتيح. |
