:::note[قيد التطوير]
يعمل مستورِد 1Password في خزنة الويب وإضافة المتصفح وتطبيقي سطح المكتب والهاتف و[واجهة سطر الأوامر](/ar/docs/platforms/cli/) (`octapass import 1password`). تُقرأ كل البيانات على جهازك.
:::

## التصدير من 1Password

1. افتح تطبيق 1Password لسطح المكتب وافتح قفله.
2. اختر **File ← Export** وحدد الحساب.
3. اختر **1PUX** (موصى به) أو **CSV**، وأدخل كلمة مرور 1Password عند الطلب.
4. احفظ الملف في مكان تتذكره، واحذفه بعد الاستيراد.

## أي صيغة تستخدم

| | 1PUX | CSV |
|---|---|---|
| بيانات الدخول وكلمات المرور وعناوين URL | نعم | نعم |
| أنواع العناصر (البطاقات والهويات والملاحظات…) | تُحفظ | تُسطَّح في الغالب إلى بيانات دخول/ملاحظات |
| الوسوم وبنية الخزنات | تُحفظ | محدودة |
| أسرار TOTP | نعم | نعم |
| الحقول المخصصة والأقسام | تُحفظ كحقول مخصصة | جزئيًا |
| المرفقات | بياناتها الوصفية فقط (يجب إضافة الملفات من جديد) | لا |
| مفاتيح المرور | لا (استخدم CXF حيث يتوفر) | لا |

## ما يُستورد

### 1PUX

الحقول كما هي موصوفة في [صيغة 1PUX](https://support.1password.com/1pux-format/) من 1Password.

| حقل 1PUX | في Octa Pass |
|---|---|
| `uuid` | يُحفظ مع العنصر، فيحدّثه استيراد الملف مرة أخرى |
| `createdAt` و`updatedAt` | تاريخا الإنشاء وآخر تغيير |
| `favIndex` | مفضّل |
| `state: archived` | يُستورد مع الوسم `archived`. أما العناصر المحذوفة فتُتخطّى |
| `categoryUuid` | نوع العنصر: بيانات الدخول وكلمات المرور والبطاقات والهويات والملاحظات تصير النوع نفسه. أما الفئات الأخرى (قاعدة بيانات، خادم، جواز سفر…) فتصير بيانات دخول إن كان فيها اسم مستخدم أو كلمة مرور، وإلا فملاحظات آمنة |
| `overview.title` و`overview.tags` | العنوان والوسوم. عند وجود عدة خزنات يُضاف اسم الخزنة كوسم |
| `overview.url` و`overview.urls` | المواقع |
| `details.loginFields` | اسم المستخدم وكلمة المرور. وتصير حقول النماذج الأخرى حقولًا مخصصة (كلمات المرور مخفية) |
| `details.sections` | حقول مخصصة بعناوينها، والحقول المخفية تبقى مخفية. تصير الرموز لمرة واحدة رمز بيانات الدخول. وفي البطاقات والهويات تملأ الحقول المعروفة (الرقم، تاريخ الانتهاء، الاسم، البريد الإلكتروني، الهاتف، العنوان…) العنصر؛ وما عداها يذهب إلى الملاحظات |
| `details.passwordHistory` | سجل كلمات المرور، بتاريخ استبدال كل كلمة مرور |
| `details.notesPlain` | الملاحظات |
| المستندات والمرفقات | لا تُستورد بعد: يأتي العنصر دون ملفه |

### CSV

صف العناوين في 1Password 8 هو `Title,Url,Username,Password,OTPAuth,Favorite,Archived,Tags,Notes`.

| عمود CSV | في Octa Pass |
|---|---|
| `Title` و`Url` و`Username` و`Password` | العنوان والموقع واسم المستخدم وكلمة المرور |
| `OTPAuth` | الرمز لمرة واحدة |
| `Favorite` | مفضّل |
| `Archived` | الوسم `archived` |
| `Tags` | الوسوم |
| `Notes` | الملاحظات |
| أي عمود آخر | حقل مخصص باسم العمود |

لا معرّفات ولا تواريخ في ملف CSV. الاستيراد مرة أخرى يجد بيانات الدخول نفسها بالموقع واسم المستخدم.

## الاستيراد إلى Octa Pass

اختر **الاستيراد ← 1Password**، وأسقط الملف، وراجع المعاينة، واختر خزنة ثم استورد. راجع [نظرة عامة على الاستيراد](/ar/docs/import-export/overview/).

## بعد الاستيراد

- افتح [لوحة السلامة](/ar/docs/features/security-dashboard/) للبحث عن كلمات المرور المعاد استخدامها أو المسرَّبة.
- لنقل مفاتيح المرور، استخدم [صيغة تبادل بيانات الاعتماد](/ar/docs/features/passkeys/#نقل-مفاتيح-المرور-بين-المديرين) حين يدعمها التطبيقان. وإلا فأضف مفتاح مرور جديدًا في كل موقع.
