:::note[قيد التطوير]
يعمل مستورِد Enpass في خزنة الويب وإضافة المتصفح وتطبيقي سطح المكتب والهاتف و[واجهة سطر الأوامر](/ar/docs/platforms/cli/) (`octapass import enpass`). تُقرأ كل البيانات على جهازك.
:::

## التصدير من Enpass

1. افتح تطبيق Enpass لسطح المكتب وافتح قفله.
2. اختر **File ← Export** (وفي بعض الإصدارات **Menu ← File ← Export**) وحدد الخزنة.
3. اختر صيغة **.json**، وأدخل كلمة مرورك الرئيسية، واحفظ الملف.

صدِّر كل خزنة على حدة إن كانت لديك عدة خزنات.

## ما يُستورد

| Enpass | Octa Pass |
|---|---|
| بيانات الدخول وكلمات المرور | بيانات دخول. أول اسم مستخدم (أو بريد إلكتروني) هو اسم المستخدم؛ وتصير الحقول الأخرى حقولًا مخصصة، مخفية حين يعلّمها Enpass حساسة. |
| الرموز لمرة واحدة | TOTP في بيانات الدخول |
| سجل كلمات المرور | سجل كلمات المرور في بيانات الدخول |
| بطاقات الائتمان | بطاقات دفع |
| الهويات | هويات. الحقول التي لا مكان لها في Octa Pass تذهب إلى الملاحظات. |
| الملاحظات الآمنة | ملاحظات آمنة |
| فئات أخرى (المال، الرخص، السفر، الحاسوب، متنوعة) | بيانات دخول حين يكون فيها اسم مستخدم أو كلمة مرور، وإلا ملاحظات آمنة، مع كل حقل |
| الوسوم والمجلدات | وسوم (`Parent/Child` حين تكون متداخلة) |
| المفضلات | المفضلات |
| العناصر المؤرشفة | تُستورد مع الوسم `archived` |
| العناصر في سلة المهملات | لا تُستورد |
| المرفقات | لا تُستورد. أضف الملفات من جديد في Octa Pass. |
| `uuid` | يُحفظ مع العنصر، فيحدّثه استيراد الملف مرة أخرى |
| `createdAt` و`updated_at` و`last_used` | تواريخ الإنشاء وآخر تغيير وآخر استخدام |
| `value_updated_at` في حقل كلمة المرور | تاريخ تغيير كلمة المرور |
| `icon` و`auto_submit` و`subtitle` و`template_type` | لا تُستورد: هذه طريقة عرض Enpass للعنصر وملئه. ويُنشأ العنوان الفرعي من جديد من اسم المستخدم |

## الاستيراد إلى Octa Pass

اختر **الاستيراد ← Enpass**، وأسقط ملف `.json`، ثم راجع واستورد. راجع [نظرة عامة على الاستيراد](/ar/docs/import-export/overview/). احذف ملف التصدير بعد ذلك: فهو غير مشفّر.
