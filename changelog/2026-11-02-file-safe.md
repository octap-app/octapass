Locking a folder with permissions doesn't protect it, so Octa Pass now encrypts.

- **`octapass encrypt` and `decrypt`:** files and folders in the [age](https://age-encryption.org) format, for yourself, other Octa Pass users, any age key, or a passphrase. They open with any age tool, and your file key can be exported to open them without Octa Pass.
- **Tools → Files in the desktop app:** drop files on the window, choose who can open them, and go. Right-click menus for Finder, Explorer, Nautilus and Dolphin bring files there.
- **Secure delete that says what it did:** `octapass shred` overwrites and removes, and tells you when your disk means that's best effort. On APFS, Btrfs, ZFS and SSDs, old copies can stay, and it says so instead of promising otherwise.
- **Octa Pass Safe:** an encrypted folder with contents and names encrypted per file, whose key is in your vault, so it locks with the vault and opens with device unlock. Turn on sync to keep it on your other devices; the server only ever sees encrypted blobs.
- **In your file manager:** a Safe can show as a folder on Linux (FUSE), in File Explorer on Windows, in Finder on a Mac, and in the Files app on Android, iPhone and iPad. Each locks with your vault. The Mac, Windows and phone versions are built but haven't been run on those systems yet.

See [Encrypting files](/docs/features/file-encryption/) and [Octa Pass Safe](/docs/features/octa-pass-safe/), including what each system can do so far.
