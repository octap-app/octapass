:::note[قيد التطوير]
كل الأنواع أدناه مبنية ما عدا نوع **العنوان** المنفصل: تُحفظ العناوين في عناصر الهوية. وتعمل الأنواع في خزنة الويب وإضافة المتصفح وتطبيقات سطح المكتب وتطبيقات الهاتف، وتقرؤها واجهة سطر الأوامر و[تُنشئها](/ar/docs/platforms/cli/#تغيير-العناصر) (مفاتيح SSH والبيئات والشهادات والمفاتيح بأوامرها الخاصة). تختلف التطبيقات في بعض المواضع: لا تعرض الإضافة من مفتاح SSH إلا مفتاحه العام وبصمته، وتُملأ الأنواع الأحدث [تلقائيًا](/ar/docs/features/autofill/#الحسابات-المصرفية-والتراخيص-والأنواع-الأخرى) في إضافة المتصفح (وقواعد البيانات عبر الكتابة التلقائية في سطح المكتب)، لا في الهواتف. راجع [مصفوفة الدعم](/ar/docs/platforms/support-matrix/#ما-يستطيع-كل-تطبيق-فعله). تبيّن **P0** و**P1** و**P2** ترتيب العمل كما خُطِّط له؛ وكله مطلوب للإصدار 1.0.
:::

## الحقول التي لكل عنصر

العنوان والوسوم وعلامة المفضلة والخزنة والملاحظات والحقول المخصصة (نص، مخفي، عنوان URL، تاريخ، بريد إلكتروني، هاتف، TOTP) والمرفقات وسجل كلمات المرور وأوقات الإنشاء والتحديث. **كلها مشفّرة**، بما فيها العناوين والوسوم. راجع [ما يراه الخادم](/ar/docs/security/what-the-server-sees/).

العنصر الذي يُجلب من تطبيق آخر يحتفظ بتواريخ ذلك التطبيق: متى أُنشئ، ومتى تغيّر آخر مرة، ومتى استُخدم آخر مرة، وفي بيانات الدخول متى تغيّرت كلمة المرور آخر مرة. ويعرض العنصر هذه التواريخ بدلًا من تاريخ وصوله إلى Octa Pass. وتعديله هنا يعيد «آخر تغيير» إلى تاريخ اليوم. ويحتفظ أيضًا بمعرّف التطبيق الآخر لهذا العنصر، فـ[استيراد الملف نفسه مرة أخرى](/ar/docs/import-export/overview/#الاستيراد-مرة-أخرى) يحدّثه بدلًا من إضافة نسخة. وهذه كلها مشفّرة مع بقية العنصر: ولا يملك الخادم سوى تواريخ المزامنة الخاصة به.

حفظ **بيانات دخول جديدة لموقع واسم مستخدم محفوظين لديك** يسألك أولًا، في خزنة الويب وتطبيق سطح المكتب وتطبيقات الهاتف: يذكر بيانات الدخول التي لديك ومكانها، ويمكنك متابعة التعديل أو حفظ نسخة رغم ذلك. ويمكن لخزنة الويب وتطبيق سطح المكتب أيضًا فتح الموجودة لديك (ويسألان قبل التخلي عمّا كتبته). تُعدّ المواقع واحدة حين يتطابق البروتوكول والمضيف دون `www.` والمنفذ، وهي القاعدة نفسها التي يستخدمها [الاستيراد](/ar/docs/import-export/overview/#الاستيراد-مرة-أخرى)؛ ولا تُقارَن بيانات الدخول التي بلا موقع. أما نافذة الحفظ في إضافة المتصفح فتعرض أصلًا تحديث بيانات الدخول التي تجدها بدلًا من ذلك.

بيانات الدخول المحفوظة من نافذة تسجيل الدخول عبر HTTP لموقع (نافذة المتصفح نفسه، لا نموذج في الصفحة) تحتفظ بـ **نطاق مصادقة HTTP** الخاص بالنافذة، ويظهر مع بيانات الدخول. يمكنك إضافة النطاق أو تغييره في محرر بيانات الدخول؛ وعندها [تجيب إضافة المتصفح عن تلك النافذة](/ar/docs/features/autofill/#نوافذ-تسجيل-الدخول-عبر-http) فقط حين يذكر الموقع النطاق نفسه.

[المرفقات](/ar/docs/features/attachments/) تعمل في خزنة الويب وإضافة المتصفح وتطبيقات سطح المكتب وتطبيقات الهاتف. تتيح الخدمة المستضافة المجانية 1 GB لكل حساب و100 MB لكل ملف.

### الموقع الواحد يظهر مرة واحدة

تعرض بيانات الدخول كل موقع مرة واحدة. ويكون العنوانان موقعًا واحدًا حين يعرض [الملء التلقائي](/ar/docs/features/autofill/#مطابقة-النطاقات) بيانات الدخول على الصفحات نفسها لكليهما، بحسب قاعدة المطابقة للعنوان الأول:

- **هذا الموقع ونطاقاته الفرعية** (الافتراضي) و**كل أجزاء هذا النطاق**: المضيف نفسه، أيًّا كانت حالة الأحرف، و`http` أو `https`، والمنفذ، والمسار، والاستعلام، و`www.` في أوله. فالعناوين `https://example.com/` و`http://www.example.com/login` و`https://example.com` موقع واحد؛ أما `a.example.com` و`b.example.com` فيبقيان موقعين.
- **هذا المضيف بالضبط**: المضيف والمنفذ نفسيهما.
- **الصفحات التي تبدأ بهذا العنوان** و**لا تعبّئ هنا أبدًا**: العنوان نفسه بعد كتابته بالطريقة القياسية (`/` بعد المضيف لا تُحتسب، و`/` في آخر مسار تُحتسب).
- **تعبير نمطي**: النص نفسه.

يبقى العنوان الأول مع قاعدة المطابقة الخاصة به. والتكرارات الموجودة أصلًا في عنصر تبقى محفوظة حتى تعدّله: يعرض العنصر كل موقع مرة واحدة، وحفظ العنصر يحذف التكرارات. ولا يضيف [الاستيراد](/ar/docs/import-export/overview/#الاستيراد-مرة-أخرى) ولا حفظ بيانات الدخول من الملء التلقائي موقعًا موجودًا أصلًا في بيانات الدخول.

## الأنواع

| النوع | الحقول الأساسية | الأولوية |
|---|---|---|
| **بيانات الدخول** | اسم المستخدم، كلمة المرور، عناوين مواقع (عدة، لكل منها [قاعدة مطابقة](/ar/docs/features/autofill/#مطابقة-النطاقات))، سر TOTP، مفاتيح المرور، البريد المُقنَّع المرتبط، [معلومات الاسترداد](/ar/docs/features/recovery-info/) | P0 |
| **مفتاح المرور** | معرّف الطرف المعتمِد، ومعرّف بيانات الاعتماد، ومقبض المستخدم، والمفتاح الخاص، والعدّاد. يُخزَّن داخل بيانات دخول أو منفردًا. راجع [مفاتيح المرور](/ar/docs/features/passkeys/). | P0 في المتصفحات، P1 على الجوال وسطح المكتب |
| **ملاحظة آمنة** | نص Markdown | P0 |

| **الهوية** | الاسم، تاريخ الميلاد، البريد الإلكتروني، الهواتف، العناوين، الشركة، المسمى الوظيفي، أرقام الهوية الوطنية | P0 |
| **العنوان** | مدخلات دفتر العناوين لملء النماذج | P0 |
| **حساب مصرفي** | المصرف، صاحب الحساب، IBAN أو رقم الحساب، رمز التوجيه/SWIFT، الرقم السري | P1 |
| **المستند** | ملف مع ملاحظات؛ يُشفَّر الملف على جهازك. يعمل في خزنة الويب وإضافة المتصفح وتطبيقات سطح المكتب وتطبيقات الهاتف. راجع [المرفقات](/ar/docs/features/attachments/). | P1 |
| **مفتاح SSH** | المفتاح الخاص والعام، نوع المفتاح، بصمة SHA256، التعليق، عبارة مرور تصدير اختيارية. أنشئ Ed25519 أو ECDSA P-256/P-384 أو RSA 3072/4096؛ واستورد OpenSSH وPEM وPKCS#8؛ وصدّر المفتاح الخاص أو سطر `authorized_keys`. مبني في خزنة الويب وتطبيقات سطح المكتب وتطبيقات الهاتف وواجهة سطر الأوامر، مع [وكيل SSH](/ar/docs/features/ssh-keys/#وكيل-ssh) في تطبيقات سطح المكتب؛ أما الإضافة فتعرض المفتاح العام والبصمة فقط. راجع [مفاتيح SSH](/ar/docs/features/ssh-keys/). | P1 |
| **شهادة** | شهادة TLS، والسلسلة، والمفتاح الخاص، والأسماء، والجهة المُصدِرة، وتاريخ الانتهاء، ونوع المفتاح، والبصمة، وما يلزم لتجديدها عبر ACME. تُنشأ في [أدوات المطورين](/ar/docs/features/developer-toolkit/)؛ ولا يُعرض المفتاح الخاص أو يُصدَّر إلا بعد أن تؤكد أنك أنت. | P2 |
| **مفتاح** | مفاتيح توقيع JWT، ومفاتيح OpenPGP وage: الجزآن الخاص والعام، وJWK وJWKS، والخوارزمية، ومعرّف المفتاح، والبصمة. تُنشأ في [أدوات المطورين](/ar/docs/features/developer-toolkit/)، مع التأكيد نفسه الذي تطلبه مفاتيح SSH. | P2 |
| **بيانات اعتماد API** | المفتاح، السر، المضيف، تاريخ الانتهاء، النوع | P1 |
| **شبكة Wi-Fi** | اسم الشبكة (SSID)، علامة الشبكة المخفية، الأمان (مفتوحة، WEP، من WPA إلى WPA3 Personal وأوضاع الانتقال بينها، وWPA2/WPA3 Enterprise مع إعدادات EAP)، كلمة المرور، صفحة تسجيل الدخول، وعلامتا الشبكة المُدارة ونقطة الاتصال الشخصية. تظهر كرمز QR؛ وتميّز التطبيقات الشبكة التي أنت عليها والشبكات في النطاق. راجع [شبكات Wi-Fi](/ar/docs/features/wifi/). | P1، في خزنة الويب والتطبيقات |
| **البيئة** | المشروع والمرحلة، وقائمة مرتبة من المتغيرات (الاسم، القيمة، علامة الإخفاء، ملاحظة). المتغير الواحد بيئة بمدخل واحد. يمكن أن تكون القيم مراجع `octapass://`. تحمّلها واجهة سطر الأوامر في الأوامر، وتكتب ملفات `.env`، وتشغّل خطّاف الصدفة. راجع [البيئات](/ar/docs/features/environments/). | P1، في كل تطبيق |
| **ترخيص برنامج** | المنتج، المفتاح، المرخَّص له، الإصدار، تفاصيل الطلب | P1 |
| **وثائق الهوية** | جواز السفر أو رخصة القيادة أو الهوية الوطنية: الرقم، الجهة المصدِرة، تاريخا الإصدار والانتهاء، الصور الممسوحة | P1 |
| **محفظة عملات مشفّرة** | اسم المحفظة، عبارة الاسترداد (مخفية)، العناوين | P2 |
| **قاعدة بيانات / خادم** | المضيف، المنفذ، المستخدم، كلمة المرور، سلسلة الاتصال | P2 |
| **قالب مخصص** | حقول تحددها أنت | P2 |

تظهر البطاقات ووثائق الهوية وتراخيص البرامج وبيانات API التي لها تاريخ انتهاء في [لوحة السلامة](/ar/docs/features/security-dashboard/) حين تنتهي أو حين يبقى على انتهائها 60 يومًا أو أقل.

## معلومات الدفع وPCI

البطاقات والحسابات المصرفية عناصر مشفّرة عادية. لا يعالج Octa Pass المدفوعات، لذلك لا ينطبق PCI-DSS. تملأ [إضافة المتصفح](/ar/docs/platforms/browser-extension/) نماذج البطاقات. ويمكنك اشتراط إعادة التحقق قبل ملء CVV.

## التوافق مع الإصدارات القادمة

مخططات العناصر لها إصدارات. وحين يفتح تطبيق أقدم عنصرًا فيه حقول لا يفهمها، يحتفظ بتلك الحقول دون مساس بدلًا من حذفها.
