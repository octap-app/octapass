يعمل مستورِد RoboForm في خزنة الويب وإضافة المتصفح وتطبيقي سطح المكتب والهاتف و[واجهة سطر الأوامر](/ar/docs/platforms/cli/) (`octapass import roboform`). تُقرأ كل البيانات على جهازك.

## التصدير من RoboForm

1. افتح تطبيق RoboForm أو إضافة المتصفح وانتقل إلى **Settings ← Account & Data ← Export**.
2. اختر **CSV file**، وحدد **Logins** و**Bookmarks** و**Safenotes**.
3. أكّد بكلمة مرورك الرئيسية واحفظ الملف.

## ما يُستورد

صف العناوين هو `Name,Url,MatchUrl,Login,Pwd,Note,Folder,RfFieldsV2`.

| RoboForm | Octa Pass |
|---|---|
| بيانات الدخول (الاسم، URL، URL المطابقة، الدخول، كلمة المرور، الملاحظة) | بيانات دخول، مع عنواني URL حين يختلفان |
| مفاتيح TOTP | TOTP في بيانات الدخول |
| حقول النماذج الإضافية (`RfFieldsV2`) | حقول مخصصة؛ تبقى حقول كلمات المرور مخفية |
| الإشارات المرجعية | بيانات دخول بعنوان URL فقط |
| Safenotes | ملاحظات آمنة |
| المجلدات، مثل `/Work/Banking` | وسوم، مثل `Work/Banking` |
| الهويات وجهات الاتصال والملفات المرفقة | ليست في CSV من RoboForm |

لا معرّفات ولا تواريخ في CSV، لذلك تعرض العناصر تاريخ استيرادها. استيراده مرة أخرى يجد بيانات الدخول نفسها بالموقع واسم المستخدم.

حقول النماذج التي تكرر اسم مستخدم بيانات الدخول أو كلمة مرورها لا تُضاف مرتين.

## الاستيراد إلى Octa Pass

اختر **الاستيراد ← RoboForm**، وأسقط الملف، ثم راجع واستورد. راجع [نظرة عامة على الاستيراد](/ar/docs/import-export/overview/).

احذف ملف التصدير بعد ذلك: فهو غير مشفّر.
