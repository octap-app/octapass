---
title: Import from Zoho Vault, Avira, Norton, McAfee True Key and Kaspersky
date: 2026-11-02
summary: Five more password managers can be imported on the device, as best effort, because none of them documents its export.
tags: [core, docs]
---

The web vault, browser extension, desktop and phone apps and the CLI can now import from [Zoho Vault](/docs/import-export/from-zoho-vault/), [Avira](/docs/import-export/from-avira/), [Norton](/docs/import-export/from-norton/), [McAfee True Key](/docs/import-export/from-mcafee/) and [Kaspersky](/docs/import-export/from-kaspersky/).

None of these apps documents its export file, so each importer follows published importers and users' reports, and has only been tested on synthetic files. Each docs page says what's known and which items the export leaves out. Kaspersky's text file can only be read in English.
