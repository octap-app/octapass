:::note[قيد التطوير]
يعمل مستورِد NordPass في خزنة الويب وإضافة المتصفح وتطبيقي سطح المكتب والهاتف و[واجهة سطر الأوامر](/ar/docs/platforms/cli/) (`octapass import nordpass`). تُقرأ كل البيانات على جهازك.
:::

## التصدير من NordPass

1. افتح تطبيق NordPass أو خزنة الويب وانتقل إلى **Settings ← Import and Export**.
2. اختر **Export Items**، ثم أكّد بكلمة مرورك الرئيسية.
3. احفظ ملف CSV (`nordpass_<date>.csv`).

## ما يُستورد

صف العناوين هو `name,url,additional_urls,username,password,note,cardholdername,cardnumber,cvc,pin,expirydate,zipcode,folder,full_name,phone_number,email,address1,address2,city,country,state,type,custom_fields`.

| NordPass | Octa Pass |
|---|---|
| كلمات المرور (الاسم، URL، اسم المستخدم، كلمة المرور، الملاحظة) | بيانات دخول |
| عناوين URL الإضافية | عناوين URL أخرى في بيانات الدخول |
| الحقول المخصصة (نص، مخفي، تاريخ) | حقول مخصصة؛ تبقى المخفية مخفية، وتصير التواريخ `YYYY-MM-DD` |
| بطاقات الائتمان (حامل البطاقة، الرقم، CVC، PIN، تاريخ الانتهاء) | بطاقات دفع؛ ويذهب الرمز البريدي إلى الملاحظات |
| المعلومات الشخصية (الاسم، البريد الإلكتروني، الهاتف، العنوان) | هويات |
| الملاحظات الآمنة | ملاحظات آمنة |
| المستندات (جواز السفر، بطاقة الهوية …) | ملاحظات آمنة بحقولها؛ NordPass لا يصدّر الملفات |
| المجلدات | وسوم |
| مفاتيح المرور والملفات المرفقة | ليست في CSV من NordPass |

لا معرّفات ولا تواريخ في CSV، لذلك تعرض العناصر تاريخ استيرادها. استيراده مرة أخرى يجد بيانات الدخول نفسها بالموقع واسم المستخدم.

لا يصدّر NordPass الرموز لمرة واحدة. أعد إعدادها من إعدادات الأمان في كل موقع.

## الاستيراد إلى Octa Pass

اختر **الاستيراد ← NordPass**، وأسقط الملف، ثم راجع واستورد. راجع [نظرة عامة على الاستيراد](/ar/docs/import-export/overview/).

احذف ملف التصدير بعد ذلك: فهو غير مشفّر.
