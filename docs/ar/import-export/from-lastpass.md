يعمل مستورِد LastPass في خزنة الويب وإضافة المتصفح وتطبيقي سطح المكتب والهاتف و[واجهة سطر الأوامر](/ar/docs/platforms/cli/) (`octapass import lastpass`). تُقرأ كل البيانات على جهازك.

## التصدير من LastPass

1. افتح إضافة LastPass للمتصفح أو خزنة الويب.
2. انتقل إلى **Account options ← Advanced ← Export** (أو **Advanced options ← Export** في خزنة الويب).
3. أكّد كلمة مرورك الرئيسية. ينزّل LastPass ملف CSV أو يعرضه كنص؛ وإن عرضه كنص فاحفظه كملف `.csv`.

## ما يُستورد

صف العناوين هو `url,username,password,totp,extra,name,grouping,fav`.

| عمود LastPass | في Octa Pass |
|---|---|
| `name` | العنوان |
| `url` | الموقع. للملاحظات الآمنة قيمة بديلة هي `http://sn`، وتُحذف |
| `username` و`password` | اسم المستخدم وكلمة المرور |
| `totp` | الرمز لمرة واحدة |
| `extra` | الملاحظات. وفي الملاحظات الآمنة المصنّفة (`NoteType:`) تملأ الحقول العنصر |
| `grouping` | وسم بمسار المجلد (`Work\Dev`) |
| `fav` | مفضّل |
| الملاحظات المصنّفة | تصير بطاقات الائتمان بطاقات دفع، وتصير العناوين هويات. أما الأنواع الأخرى التي فيها اسم مستخدم أو كلمة مرور (الخوادم وقواعد البيانات وحسابات البريد الإلكتروني) فتصير بيانات دخول، والباقي ملاحظات آمنة. الحقول التي لا مكان لها تذهب إلى الملاحظات كأسطر `Label: value` |
| المرفقات | ليست في CSV |

لا معرّفات ولا تواريخ في CSV، لذلك تعرض العناصر تاريخ استيرادها. استيراده مرة أخرى يجد بيانات الدخول نفسها بالموقع واسم المستخدم، والملاحظات نفسها بالعنوان والنص.

## بعد الاستيراد

إن كنت تستخدم LastPass قبل اختراقه عام 2022، فاعتبر كلمات المرور التي كانت مخزنة فيه حينها مكشوفة. استخدم [لوحة السلامة](/ar/docs/features/security-dashboard/) لتغيير أهمها واحدة واحدة، بدءًا من البريد الإلكتروني والبنوك.
