يعمل مستورِد Raivo OTP في خزنة الويب وإضافة المتصفح وتطبيقي سطح المكتب والهاتف و[واجهة سطر الأوامر](/ar/docs/platforms/cli/) (`octapass import raivo`). تُقرأ كل البيانات على جهازك.

## التصدير من Raivo OTP

1. في Raivo OTP على iPhone أو iPad، افتح **Settings ← Export**.
2. احفظ ملف ZIP. يشفّره Raivo بكلمة مرورك الرئيسية في Raivo، فجهّزها.
3. أبقِ ملف ZIP كما هو. ويمكن أيضًا استيراد `raivo-otp-export.json` الذي بداخله وحده.

يكتب Raivo أيضًا في ملف ZIP صفحة HTML فيها رموز QR. لا يقرأ Octa Pass هذه الصفحة: ففي JSON كل شيء.

## ما يُحفظ

| Raivo | Octa Pass |
|---|---|
| رموز TOTP (SHA-1 وSHA-256 وSHA-512، من 6 إلى 8 أرقام) | الرمز لمرة واحدة في بيانات الدخول |
| جهة الإصدار والحساب | عنوان بيانات الدخول واسم المستخدم |
| `pinned` | مفضّل |
| `kind: HOTP` | [رموز معتمدة على عدّاد](/ar/docs/features/totp/#الرموز-المعتمدة-على-عدّاد-hotp)، مع عدّادها |
| `kind: Steam` وأنواع أخرى | حقل مخفي في بيانات الدخول مع الإعداد الكامل. لا يستطيع Octa Pass عرض هذه الرموز بعد. |
| الأيقونات (`iconType` و`iconValue`) | لا تُستورد |
| قيود بلا سر | تُتخطّى، مع تحذير |

لا معرّفات ولا تواريخ في تصدير Raivo. استيراد الملف نفسه مرة أخرى يجد الرموز بسرّها بدل إضافتها مرتين. والرمز الذي ينضم إلى بيانات دخول لديك لا يُضاف إلى بيانات دخول أخرى.

## الاستيراد إلى Octa Pass

اختر **الاستيراد ← Raivo OTP**، وأسقط ملف ZIP (أو ملف JSON الذي بداخله)، وأدخل كلمة المرور الرئيسية في Raivo إن كان الملف مشفّرًا، ثم راجع واستورد. راجع [نظرة عامة على الاستيراد](/ar/docs/import-export/overview/).
