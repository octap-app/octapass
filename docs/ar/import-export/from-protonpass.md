يعمل مستورِد Proton Pass في خزنة الويب وإضافة المتصفح وتطبيقي سطح المكتب والهاتف و[واجهة سطر الأوامر](/ar/docs/platforms/cli/) (`octapass import protonpass`). تُقرأ كل البيانات على جهازك.

## التصدير من Proton Pass

1. افتح Proton Pass (تطبيق الويب أو تطبيق سطح المكتب أو إضافة المتصفح) وانتقل إلى **Settings ← Export**.
2. اختر **ZIP** أو **JSON**. يمكن أن يكون ملف ZIP **مشفّرًا بـ PGP بعبارة مرور**: يقرؤه Octa Pass على جهازك بتنفيذ OpenPGP مكتوب بلغة Rust الخالصة.
3. يعمل **CSV** أيضًا، لكنه يترك الحقول المخصصة ومفاتيح المرور وتفاصيل Wi-Fi.
4. أكّد بكلمة مرور Proton واحفظ الملف.

## ما يُستورد

| Proton Pass | Octa Pass |
|---|---|
| بيانات الدخول (عناوين URL، اسم المستخدم، البريد الإلكتروني، كلمة المرور، الملاحظات) | بيانات دخول. إن كان فيها اسم مستخدم وبريد إلكتروني معًا، يصير البريد الإلكتروني حقلًا مخصصًا. |
| TOTP (`totpUri`) | TOTP في بيانات الدخول |
| حقول إضافية (نص، مخفي، TOTP، تاريخ) | حقول مخصصة في بيانات الدخول؛ وأسطر في ملاحظات الأنواع الأخرى |
| الملاحظات | ملاحظات آمنة |
| بطاقات الائتمان | بطاقات دفع |
| الهويات | هويات. الحقول التي لا مكان لها في Octa Pass (جواز السفر، الشركة، الروابط الاجتماعية …) تذهب إلى الملاحظات. |
| الأسماء المستعارة (Aliases) | بيانات دخول بعنوان الاسم المستعار كاسم مستخدم. يواصل الاسم المستعار إعادة التوجيه من حساب Proton الخاص بك. |
| مفاتيح المرور | تبقى في بيانات الدخول، لكنها لا تستطيع تسجيل دخولك بعد |
| شبكات Wi-Fi | بيانات دخول بكلمة المرور وSSID ونوع الأمان |
| مفاتيح SSH والعناصر المخصصة | ملاحظات آمنة بكل حقولها |
| تصدير مشفّر بـ PGP (`data.pgp` أو ملف `.pgp`) | يُفك تشفيره بعبارة مرور التصدير قبل قراءة أي شيء. عبارة مرور خاطئة، أو بايت تغيّر، أو ملف مقطوع، لا يستورد شيئًا. |
| `itemId` (ZIP وJSON) | يُحفظ مع العنصر، فيحدّثه استيراد الملف مرة أخرى |
| `createTime` و`modifyTime` | تاريخا الإنشاء وآخر تغيير (وفي CSV أيضًا) |
| `lastUseTime` | تاريخ آخر استخدام، حيث يحويه التصدير (تقدير: لم نره في كل التصديرات) |
| `pinned` | مفضّل |
| الخزنات والمجلدات | وسوم (أسماء الخزنات فقط حين تصدّر عدة خزنات) |
| إعدادات مطابقة URL | تُحفظ حيث توجد قاعدة مطابقة مقابلة في Octa Pass |
| العناصر في سلة المهملات | لا تُستورد |
| المرفقات | لا تُستورد بعد |

لا معرّفات في تصدير CSV. استيراده مرة أخرى يجد بيانات الدخول نفسها بالموقع واسم المستخدم.

التصدير المشفّر رسالة OpenPGP بعبارة مرور (`encryptPassExport` في شيفرة Proton Pass نفسها): OpenPGP.js، مع S2K مكرَّر وبملح، وAES-256. يستخدم Octa Pass مكتبة rPGP، وهي تنفيذ OpenPGP بلغة Rust الخالصة، فيُفك تشفير الملف على الجهاز في كل التطبيقات. يبقى حجم تنزيل خزنة الويب صغيرًا بإبعاد OpenPGP عنه؛ ولا تحمّل البنية الكاملة إلا حين تستورد ملف Proton Pass مشفّرًا. أما التصدير المقفل بحساب Proton الخاص بك (لا بعبارة مرور) فما زال لا يمكن قراءته.

## الاستيراد إلى Octa Pass

اختر **الاستيراد ← Proton Pass**، وأسقط ملف `.zip` أو `.pgp` أو `.json` أو `.csv`، وأدخل عبارة مرور التصدير إن كان الملف مشفّرًا، ثم راجع واستورد. راجع [نظرة عامة على الاستيراد](/ar/docs/import-export/overview/). احذف ملف التصدير بعد ذلك ما لم يكن مشفّرًا.
