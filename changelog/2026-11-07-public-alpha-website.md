The hosted service, the sync server and the web vault on one origin, is open at [vault.octap.app](https://vault.octap.app) as a public alpha with open sign-ups. The web vault is the one thing you can use today: none of the apps is in a store yet. They're built and coming soon. Nothing has had its external security audit, so don't rely on Octa Pass alone for anything important yet.

On the website, in English and Arabic:

- **Hero.** "Create a free account" opens the web vault, and the status line says the alpha is open and the apps are coming to the stores.
- **Platforms.** Every platform shows where to get it: "Open web vault" for the web, and "Coming soon" for the apps until each store listing is live. Safari, the CLI, VS Code and JetBrains IDEs now have their own entries. Each one links to its source folder in the repository.
- **Open source.** Links to the GitHub repository, the MIT licence, the contributing guide, the security policy, issues and the [self-hosting guide](/docs/self-hosting/overview/). The top bar has a GitHub link, and the footer links the licence and the contributing guide.

The [overview](/docs/getting-started/overview/), [quick start](/docs/getting-started/quick-start/), docs home and [FAQ](/docs/reference/faq/) say the same: create your account in the web vault now, and the store apps follow.
